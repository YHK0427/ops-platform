# 기수원 로그인

## 진입 경로
- 로그아웃 상태에서 `/login`(통합 로그인) 진입 시, 기수원 계정으로 판별되면 자동으로 이 화면 흐름을 탄다(실제로는 `MemberLoginPage`가 `/login` 라우트 자체를 처리하며, 통합 `LoginPage`와 별개 컴포넌트다 — 라우팅 구조는 App.tsx 확인 필요, 이 파일만으론 어느 URL에 물려있는지 불명확 — **코드상 불명확, 실제 화면 확인 필요**).
- URL 패턴: 컴포넌트명 `MemberLoginPage` (참고용).

## 화면 구성
- 가운데 정렬된 카드(흰 배경, 둥근 모서리, 그림자).
- 상단: 작은 회색 대문자 라벨 "UNIVPT" + 큰 제목 "발표 성장 리포트"(그라데이션 텍스트).
- 기본 상태: 로그인 폼.
- 기수 모호 상태: 기수 선택 리스트로 전환.

## 버튼/액션 전수 목록

### 로그인 폼 (기본 상태)
- **"이름" 입력창** — 텍스트, `autoComplete="username"`, placeholder "이름". 필수.
- **"비밀번호" 입력창** — `type="password"`, `autoComplete="current-password"`, placeholder 없음. 필수.
- **"로그인" 버튼** (그라데이션 rose 배경, 전체 폭)
  - 클릭 시(또는 폼 Enter 제출): 아이디+비밀번호로 로그인 시도.
  - 로딩 중엔 버튼 안 스피너 아이콘 + 텍스트가 "로그인 중..."으로 바뀌고 버튼 비활성화.
  - 성공: `/member` 로 이동(뒤로가기로 로그인 화면 복귀 불가하도록 `replace`).
  - 같은 아이디가 여러 기수에 존재: 에러 없이 기수 선택 리스트 화면으로 전환.
  - 실패(아이디/비번 틀림): 폼 위에 빨간 텍스트 "이름 또는 비밀번호가 올바르지 않습니다." 표시, 화면 전환 없음.

### 기수 선택 리스트 (같은 아이디가 여러 기수에 있을 때만 표시)
- 안내 문구: "같은 아이디가 여러 기수에 있어요. 어느 기수인가요?"
- **기수별 버튼**(기수 개수만큼 반복, 라벨 = 기수 이름 예: "34기")
  - 클릭 시: 그 기수로 즉시 로그인 시도(별도 확인 버튼 없이 바로 진행).
  - 로딩 중엔 모든 기수 버튼 비활성화.
  - 성공 시 `/member`로 이동, 실패 시 리스트 위에 에러 문구 표시.
- **"돌아가기" 버튼**(화살표 아이콘 + 텍스트, 하단)
  - 클릭 시: 기수 선택 리스트를 닫고 처음 로그인 폼으로 되돌아감(입력했던 아이디/비번은 유지됨 — state 초기화 안 함).

## 폼/입력 필드
| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 이름(아이디) | text | 예 | 브라우저 자동완성 username |
| 비밀번호 | password | 예 | 브라우저 자동완성 current-password |

- 별도 프론트엔드 검증 규칙 없음(HTML `required`만). 서버 응답에 따라 에러 문구 하나만 노출(구체적 실패 사유 구분 없음 — 아이디 틀림/비번 틀림 모두 동일 메시지).

## 상태별 화면
- **로딩 중**: 로그인 버튼(또는 선택한 기수 버튼)이 비활성화되고 스피너 표시. 별도 전체 화면 로딩 오버레이는 없음.
- **에러**: 폼/리스트 바로 아래 작은 빨간 텍스트 한 줄. 입력값은 지워지지 않음.
- **빈 상태**: 해당 없음(폼 화면이라 목록 없음).

## 알아두면 좋은 것
- 로그인 성공 시 "로그인 유지"류의 옵션 UI는 이 화면에 없음 — 뒷단(`useMemberAuth`)에서 항상 장기 세션으로 처리하는 것으로 보임(다른 세션에서 "기수원은 로그인 유지가 사실상 무제한"이라는 백엔드 설명과 일치).
- 기수 선택은 "비밀번호가 이미 기수마다 다르게 설정돼 있으면" 애초에 뜨지 않고 바로 로그인됨 — 같은 아이디+같은 비밀번호를 쓰는 기수가 여러 개일 때만 이 화면이 뜬다.
- 되돌릴 수 없는 액션 없음(단순 로그인 폼).
