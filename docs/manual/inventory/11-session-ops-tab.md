# 세션 상세 — "과제 준비" 탭 (OPS)

## 진입 경로
- 세션 상세 화면 상단 탭 바에서 "과제 준비" 클릭(세션 상태가 OPS 이상이어야 클릭 가능 — PREP 상태에서는 회색으로 잠김)
- URL: `/sessions/{id}/ops`
- 이 탭에서 상단 상태 전환 버튼("과제 검사 시작")을 누르면 다음 탭(과제 검사)이 열림
- 상세 헤더/탭바/기한표시줄은 "출석" 탭 문서 참고(공통)

## 화면 구성
- **다음 날 경고 배너**: 세션 날짜의 다음날에 이 화면을 열면 "영상 업로드 마감 경고 — 오늘은 세션 다음 날입니다. 자정 전까지 영상 업로드를 완료해주세요" 주황색 배너가 최상단에 표시
- **영상 직접 업로드 패널** (항상 표시)
- **피드백 대상 지정 패널** (세션에 "영상 피드백" 옵션이 켜져 있고, 피드백 배정 데이터가 이미 존재할 때만 표시)

### 영상 직접 업로드 패널

**상단 우측 링크**: "발표 순서 변경" / "발표 순서 편집 닫기" — 클릭하면 패널이 펼쳐지고 드래그로 발표 순서(또는 팀 순서)를 바로 조정할 수 있음. 조정한 순서는 즉시 저장되고, 아래 업로드 목록의 "(N번째)" 표시와 카페 제목에도 바로 반영됨. (조작 방법은 "출석" 탭 문서의 "발표 순서" 뷰와 동일한 드래그+화살표 버튼 UI)

**헤더**: "영상 직접 업로드" + "N/M개 완료" + (업로드 중이면) "N개 업로드 중"
**우측 버튼**: **"네이버 업로드 (N개)"** — 체크된 영상들을 네이버 카페에 자동 업로드 시작. 하나도 안 골랐거나, 서버 처리/압축 중인 항목이 섞여 있으면 비활성화(버튼 라벨이 "서버 처리 중 (N개)" 또는 "압축 중 (N개)"으로 바뀌어 이유를 알려줌)

**안내 문구**: "체크된 영상만 네이버 카페에 업로드됩니다. 1분반 → 2분반 순서로 발표 순서대로 진행됩니다."

**카페 제목 접두어 입력창**: 기본값 "연합UP {기수명} {N}주차 발표-[{세션제목}]-" — 직접 수정 가능. 바꾸면 아래 개별 제목들도 갱신됨

**분반별(또는 전체) 목록 — 각 발표자(또는 팀) 행**:
- 좌측 **체크박스**: 네이버 업로드 대상 선택/해제. 영상이 없으면 체크 불가(서버 처리 중인 상태는 예외적으로 체크는 가능, 업로드는 처리 끝날 때까지 대기)
- 분반/전체 헤더에도 **전체 선택 체크박스**(그 그룹 내 영상 있는 사람 전체를 한번에 체크/해제)
- 순번, 이름(팀이면 팀명 + 소속 멤버 이름 부제)
- 상태 배지: "서버 처리 중"(주황, 깜빡임) / "압축 중"(남색, 깜빡임) / 카페 업로드 진행 상태(대기/업로드중/다운중/완료/실패/취소, 색상별)
- **영상 없을 때**: 만약 이전에 실패했으면 에러 메시지 표시, 우측에 **"영상 선택" 버튼** — 클릭하면 파일 선택창(비디오 파일만)이 열리고 고르는 즉시 업로드 시작
- **업로드 중일 때**: 진행률 바(%) + **"중지" 버튼**(클릭하면 업로드 중단)
- **대기열에 있을 때**(동시 업로드 3개 제한 초과분): "업로드 대기 중..." + **"취소" 버튼**
- **업로드 완료(영상 있음)일 때**: 초록 체크 + 파일명 + 용량(MB) + **"교체" 버튼**(다시 파일 선택해서 덮어쓰기) + **삭제 아이콘**(휴지통, 클릭 시 바로 삭제 — 확인창 없음)
- **영상이 있는 행 하단**: 카페 게시글 제목 인라인 편집 입력창(직접 고쳐 쓸 수 있음) + (팀 세션이면) **"팀원명 추가"/"팀원명 표시중" 토글 버튼** — 제목에 팀원 이름을 괄호로 덧붙일지 결정

**하단**: "업로드 대상에서 제외 (N명)" 박스 — 결석/공결 처리된 사람들이 여기 이름+상태 배지로 표시(위 목록에서는 아예 안 보임)

**업로드 결과 배너** (네이버 업로드가 끝나면 표시): 성공/실패 건수, 실패 항목은 발표자명+에러 사유 목록. 진행 중일 때는 "네이버 카페 업로드 진행 중" + 진행률 + 현재 업로드 중인 발표자 이름 + **"중단" 버튼**(전체 작업 취소)

### 피드백 대상 지정 패널
- 헤더: "피드백 대상 지정" — "각 멤버가 피드백을 작성할 대상을 지정합니다. 본인 영상은 기본 포함됩니다."
- 우측 버튼 3개:
  - **"초기화"**: 모든 피드백 배정을 비움(확인창 없이 바로 실행)
  - **"복사"**: 작성자별 배정 대상 명단을 표 형식(엑셀/노션에 붙여넣기 가능한 형식)으로 클립보드에 복사. 배정이 하나도 없으면 "복사할 피드백 배정이 없습니다" 에러
  - **"랜덤 배정"**: 자동으로 각 작성자에게 피드백 쓸 대상을 랜덤 배정(결석자는 더 많이 배정됨)

**좌측: 배정 표** — 행마다 "피드백 작성자" 이름(분반 배지 포함, 결석자는 "결석 · 2개" 배지) + "피드백 대상" 칸에 현재 배정된 대상 이름 뱃지들(각 뱃지 우측 X로 개별 제거 가능) + **"추가" 버튼**(클릭하면 검색 가능한 드롭다운 목록이 뜨고 이름 선택하면 대상에 추가됨)

**우측: 발표자(피드백 수신) 현황 패널** — 각 발표자 이름 옆에 "N명" 배지(받는 피드백 개수, 0명이면 빨간색으로 경고), 마우스 올리면(hover) 보라색으로 강조되면서 좌측 표에서 그 사람을 대상으로 지정한 작성자 행들도 같이 강조됨(연결 관계 파악용). 각 항목 우측 X 버튼으로 "발표자 목록"에서 제거 가능(발표자가 아니게 됨 = 피드백을 못 받게 됨). 하단 **"발표자 추가" 버튼**으로 목록에 없는 사람을 발표자로 추가 가능(결석자는 "결석" 표시가 붙어서 나옴)

## 알아두면 좋은 것
- 영상 삭제, 피드백 배정 "초기화"는 확인창 없이 **즉시 실행**됨
- iOS(아이폰/아이패드)에서 업로드 시작하면 "화면 나가지 말아달라"는 경고가 뜸 — 화면을 벗어나면 업로드가 끊길 수 있음(iOS 정책)
- 업로드 중에는 화면이 자동으로 꺼지지 않도록 잠금(Wake Lock)이 걸림 — 업로드가 다 끝나면 자동 해제
- 파일 용량이 크면(약 50MB 초과) 자동으로 더 빠른 방식(R2 직접 업로드)으로 전환되고, 그 설정이 안 돼 있으면 서버 경유 방식으로 자동 대체됨 — 사용자가 신경 쓸 필요 없음, 그냥 파일만 고르면 됨
- "네이버 업로드" 버튼은 한 번 누르면 백그라운드로 순차 진행되며, 다른 운영진이 같은 세션 화면을 열어도 진행 상황이 공유되어 보임
