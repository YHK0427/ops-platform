# 멤버

## 진입 경로
- 사이드바 "**멤버**" (Users 아이콘) — 모든 운영진(admin/manager/viewer)에게 보임.
- 대시보드의 "위험 인물 한눈에" 카드에서 이름 칩을 눌러도 오는 건 아님(그건 멤버 상세로 바로 감) — 이 목록 화면 자체는 사이드바로만 진입.
- URL: `/members`

## 화면 구성
- 상단: "멤버" 제목 + 부제(총 N명 · 디파짓 충전 필요 N명 · 벌금 미납 N명 · 벌금 임박 N명 — 해당 인원이 0명이면 그 항목 자체가 부제에서 빠짐) + 우측에 **"멤버 추가"** 버튼
- 검색창 + 필터 옵션 줄
- **데스크탑**: 표(테이블) 형태 — No. / 이름·이메일 / 태그 / 디파짓 / 벌금 미납 / 상점 / 벌점 / 순점수 / 가입일
- **모바일**: 카드 리스트 형태 — 이름/순번/이메일/태그가 위에, 디파짓·미납·상벌점이 3칸 그리드로 아래에

## 버튼/액션 전수 목록

### 상단
- **"멤버 추가"** 버튼(우상단, 진한 색) — 클릭 시 우측에서 슬라이드로 "새 멤버 추가" 패널(Sheet)이 열림 (아래 폼 참조)

### 검색·필터 줄
- **검색창**("이름 또는 이메일 검색...") — 입력하는 즉시 목록이 실시간으로 필터링됨(이름 또는 이메일에 포함된 문자열 기준, 대소문자 구분 없음)
- **"주의 인원만"** 토글 버튼(경고 아이콘) — 누르면 활성화(빨간 배경)되어 벌점 임박·디파짓 부족·벌금 미납 중 하나라도 해당하는 멤버만 표시. 다시 누르면 해제
- **"비활성 멤버 포함"** 체크박스 — 체크하면 이탈/수료 처리된 멤버도 목록에 같이 표시됨(기본은 활성 멤버만)
- 우측 끝 **필터 아이콘 버튼** — 클릭 시 별도 동작 없음(코드상 onClick 핸들러 없음 — 장식용이거나 미구현 상태로 보임, 실제 화면 확인 필요)

### 목록(표/카드) 행
- **행 전체를 클릭**하면 해당 멤버의 상세 페이지(`/members/{id}`)로 이동 (데스크탑 표/모바일 카드 둘 다 동일)
- 이름 옆에 배지가 붙는 경우:
  - 비활성 멤버면 "이탈"(붉은색) 또는 "수료"(하늘색) 배지
  - 디파짓이 10,000원 미만이면 "충전요망" 빨간 배지
  - 벌금 미납이 있으면 "납부필요" 빨간 배지
  - 누적벌점이 다음 5천원 벌금 구간(-10/-20/-30...)까지 3점 이내로 남았으면 "벌금임박" 배지(마우스 올리면 정확히 몇 점 남았는지 툴팁으로 표시)
- 순점수는 양수면 초록, 음수면 빨강, 0이면 회색으로 자동 색상 표시
- 정렬/페이지네이션: 코드상 없음 — 전체 목록이 한 번에 다 로드되어 표시됨(정렬 기준은 서버가 내려주는 순서 그대로).

## 폼/입력 필드 — "멤버 추가" 패널
- **이름** (텍스트, 필수) — 비어있으면 "멤버 생성" 버튼이 비활성화됨
- **이메일** (이메일 타입, 선택)
- **태그** — 추천 태그 5개(리더/백엔드/프론트엔드/디자이너/기획) 버튼을 눌러 토글하거나, "직접 입력..." 칸에 원하는 태그를 쳐서 **"추가"** 버튼(또는 Enter)으로 커스텀 태그 추가. 선택된 태그는 목록 아래 칩으로 표시되고 각 칩의 "×"로 제거 가능
- 하단 안내문구: "새로운 멤버를 추가합니다. 초기 디파짓은 0원으로 시작합니다."
- 제출 버튼: **"멤버 생성"** (이름 비어있거나 처리 중이면 비활성화, 처리 중엔 "생성 중..."으로 표시) — 성공 시 패널이 자동으로 닫히고 입력값 초기화됨. 실패 시 토스트로 에러 표시(구체 문구는 코드상 불명확 — 실제 화면 확인 필요).

## 상태별 화면
- **로딩 중**: 표는 "로딩 중..." 텍스트 한 줄, 모바일은 동일 문구를 카드 자리에 표시
- **데이터 없음**(검색/필터 결과 없음 포함): "데이터가 없습니다." 표시
- **에러**: 코드상 별도 에러 UI 없음 — 실제 화면 확인 필요.

## 알아두면 좋은 것
- "비활성 멤버 포함"을 체크하지 않으면 이탈/수료 처리한 멤버는 목록에서 아예 안 보인다 — 옛날 멤버를 찾을 때는 이 체크박스부터 켜야 함.
- 이 화면에서는 멤버를 삭제(이탈 처리)할 수 없다 — 그건 멤버 상세 페이지의 기능임(03-member-detail.md 참조).
- "주의 인원만" 필터는 검색어와 동시에 적용 가능(둘 다 만족하는 멤버만 표시).
