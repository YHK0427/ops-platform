# 세션 상세 — "출석" 탭 (PREP)

## 진입 경로
- "전체 세션"에서 세션 카드 클릭 → 세션 상세 화면 진입 시 기본 탭. 또는 세션 상세 화면 상단 탭 바에서 "출석" 클릭
- URL: `/sessions/{id}/prep`
- **탭 잠금 규칙**: 세션 상태가 `SETUP`/`PREP`일 때는 "출석" 탭만 클릭 가능(나머지 탭은 회색 글씨로 비활성, 클릭 안 됨). `OPS` 이상으로 진행하면 "과제 준비" 탭도 열림(이하 마찬가지로 순차 해제, 한 번 열리면 뒤로 가도 계속 열려 있음)

## 화면 구성 (세션 상세 공통 헤더 — 모든 탭에 공통)
- 최상단: 뒤로가기 화살표 + "[N주차] 제목" + "날짜 (개인/팀)" 부제
- 우측 액션 영역:
  - **"세션 삭제"** 버튼(빨간색, 휴지통 아이콘) — `FINALIZED` 상태가 아닐 때만 보임. 클릭 시 "세션을 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다" 확인창 → 확인하면 즉시 삭제
  - **상태 전환 버튼** (파란/보라/초록색, 세션 상태에 따라 라벨 바뀜):
    - SETUP 상태: "출석 시작"(개인) 또는 "팀 확정 (출석 시작)"(팀) → 클릭 시 확인창 "세션 상태를 '출석' 단계로 변경하시겠습니까?" → PREP으로 전환
    - PREP 상태: "과제 준비 시작" → OPS로 전환
    - (OPS/POST 단계 버튼은 각 탭 문서 참고)
  - "세션 확정됨" 라벨(자물쇠 아이콘) — `FINALIZED` 상태일 때만 표시
  - 상태 배지(현재 상태를 색깔 있는 텍스트로 표시)
- 탭 바: 출석 / 과제 준비 / 과제 검사 / 정산 (가로 스크롤 가능, 현재 탭은 밑줄 강조)
- **기한 표시줄**(제출 기한을 하나라도 설정했을 때만 보임): "PPT 이메일: 날짜시간 · 지각: 날짜시간 · 후속 과제: 날짜시간" 형태로 표시. 우측 끝에 연필 아이콘 — 클릭하면 인라인 편집 모드(날짜/시간 입력창 3개 + 체크(저장)/X(취소) 버튼). `FINALIZED`면 편집 버튼 자체가 안 보임

## "출석" 탭 전용 구성
상단에 2칸 그리드(모바일은 1열):

### 1. PPT 이메일 스캔 카드 — **폐지된 기능, 매뉴얼에 넣지 말 것**
- 세션에 "PPT 이메일 제출" 옵션이 켜져 있을 때만 표시되지만, 실제 운영에서는 더 이상 사용하지 않는 기능. 카드 전체가 반투명 오버레이 + "미구현" 라벨로 덮여 있고 버튼("PPT 이메일 스캔", "전체 PPT 다운로드")도 비활성화돼 있음
- Phase 3 사용설명서 작성 시 이 카드는 아예 다루지 않는다(사용자에게 죽은 기능을 소개할 필요 없음)

### 2. 사유서 스캔 카드
- **"사전사유서" 버튼**: 네이버 카페 사전 사유서 게시판을 스캔하는 백그라운드 작업을 시작. 클릭하면 "사전사유서 스캔이 시작되었습니다" 토스트 뜨고, 바로 아래 진행상황 박스가 나타남(스피너→완료 체크/실패 X 아이콘, 작업 ID 일부 표시)
- **"사후사유서" 버튼** (주황색): 사후 사유서 게시판 스캔. 동작은 위와 동일
- **"삭제" 버튼** (빨간색, 휴지통 아이콘): 클릭 시 "사유서 데이터(사전/사후 구분, 사유서 내용)를 모두 초기화합니다. 계속하시겠습니까?" 확인창 → 확인하면 이 세션의 모든 사유서 기록이 초기화됨(되돌리기 불가)

### 3. 출석 체크 섹션
- 섹션 제목 "출석 체크" 옆에:
  - **"팀 수정" 버튼** — 팀 세션이고 상태가 PREP일 때만 표시. 클릭 시 팀 편집 화면(`/sessions/{id}/team-edit`)으로 이동
  - **"분반 수정" 버튼** — 개인 세션+분반 옵션 켜져 있고 상태가 SETUP/PREP일 때만 표시. 클릭 시 분반 편집 화면(`/sessions/{id}/group-edit`)으로 이동

#### 출석표(뷰 전환 토글 있음)
상단에 "출석 관리" / "발표 순서" 두 개 탭 버튼(알약 모양)으로 뷰를 전환.

**"출석 관리" 뷰** (기본값)
- 우측에 **"일괄 출석 처리" 버튼**(빨간 배경): 아직 상태가 "미처리"인 인원 전체를 확인창("N명의 미처리 인원을 '출석'으로 일괄 처리하시겠습니까?") 통과 시 한 번에 "출석"으로 변경
- 팀/분반별로 구간이 나뉘어 표시(분반이면 파란/초록 점으로 구분 + 담당 운영진 이름도 표시)
- **데스크탑**: 표 형태. 열 = 팀(팀 구분 없으면 생략) / 멤버 이름(비활성 멤버는 "비활성" 배지) / 출결 드롭다운 / 메모 입력창 / 사유서(유형 드롭다운 + 내용 있으면 문서 아이콘→팝오버로 원문 표시) / PPT 이메일(제출/지각/미제출/면제 버튼 4개, 팀 세션이면 팀당 대표 1명만 조작 가능하고 나머지는 읽기전용 배지)
  - **출결 드롭다운 선택지**: 미처리 / 출석 / 지각(10분 미만) / 지각(10분 초과) / 조퇴 / 결석 / 공결 — 선택 즉시 저장(별도 저장 버튼 없음), 저장 중엔 옆에 회전 아이콘
  - **메모 입력창**: 자유 텍스트, 입력 후 포커스를 벗어나면(다른 곳 클릭) 자동 저장, Enter 키로도 저장됨
  - **사유서 유형 드롭다운**: "-" / 사전 통보 / 사후 제출 — 선택 시 "사유서가 업데이트되었습니다" 토스트
  - **PPT 이메일 버튼 4개**(제출/지각/미제출/면제): 이미 선택된 걸 다시 누르면 "미검사"로 초기화됨(안내 툴팁 있음)
- **모바일**: 카드 리스트. 한 줄에 이름+상태점+사유서아이콘 + 사유유형/출결 드롭다운(축약형) + 펼침 화살표. 탭하면 펼쳐져서 PPT 버튼과 메모 입력창이 나타남

**"발표 순서" 뷰**
- 개인 세션: 분반이 있으면 "1분반"/"2분반" 두 박스로 나뉘고, 없으면 "전체" 박스 하나. 결석/공결 처리된 사람은 발표 순서 목록에서 빠지고 하단에 "발표 순서에서 제외 (N명)" 박스에 이름+상태 배지로 따로 표시
- 팀 세션: "팀 발표 순서" 박스 하나에 팀들이 나열(팀명 + 소속 멤버 이름 목록)
- **각 행**: 좌측 드래그 손잡이(⋮⋮ 아이콘) — 데스크탑은 마우스로 드래그, 모바일은 길게 눌러서 드래그. 모바일에는 추가로 우측에 **▲(위로 이동) / ▼(아래로 이동) 버튼**이 있어 드래그 없이도 순서 변경 가능(맨 위/맨 아래 항목은 해당 버튼 비활성)
- 순서를 바꾸면 **자동 저장**됨(별도 저장 버튼 없음)

## 알아두면 좋은 것
- 사유서 삭제, 세션 삭제는 확인창을 통과하면 **즉시 되돌릴 수 없이 실행**됨
- PPT 이메일 스캔 카드는 폐지된 기능 — 사용설명서에서 제외
- 발표 순서 변경은 저장 버튼이 따로 없고 드래그/버튼 클릭 즉시 반영됨
