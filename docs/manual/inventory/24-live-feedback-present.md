# 실시간 피드백 — 발표용 전체화면

## 진입 경로
- "실시간 피드백" 관리 화면(→ `23-live-feedback-management.md`)의 보드 카드에서 **전체화면 아이콘 버튼**을 누르거나, "라이브 보기" 탭에서 보드를 고른 뒤 **"전체화면" 버튼**을 누른다.
- URL: `/live-feedback/{보드ID}/present`
- 이 화면은 사이드바가 없는 완전 별도 화면이다(강의실 프로젝터/큰 화면 투사용).

## 화면 구성
어두운 배경(짙은 회색) 전체화면. 상단 바 + 발표자 이름 헤더 + 피드백 카드 그리드.

### 상단 바
- 왼쪽: 보드 제목 + 연결 상태("실시간"/초록 와이파이 아이콘 또는 "연결 중"/회색)
- 오른쪽에 순서대로:
  - **◀ 이전 발표자 버튼**
  - **발표자 선택 드롭다운**(분반 번호 + 이름)
  - **▶ 다음 발표자 버튼**
  - **카드 크기 조절**: "－" 버튼(누르면 카드가 작아지며 한 줄에 더 많이 보임, 최대 5열) / 현재 열 수 숫자 / "＋" 버튼(누르면 카드가 커지며 한 줄에 적게 보임, 최소 1열)
  - **"익명 적용" 체크박스**: 켜면(기본 켜짐) 익명으로 쓰인 글은 화면에도 실명 대신 별명만 보여준다(청중에게 작성자 숨김). 끄면 운영진 화면 기준 실명이 그대로 뜬다.
  - **닫기(X) 버튼**: "실시간 피드백" 관리 화면으로 돌아간다.

### 본문
- 발표자 이름을 큰 글씨로 표시(분반 있으면 분반 번호도 같이), 그 옆에 "N개 피드백"
- 그 아래 피드백 카드들이 Pinterest 스타일 여러 열로 나열됨(열 개수는 위에서 조절한 값)
- 카드 하나하나: 작성자 이름(또는 익명 적용 시 별명) + 운영진 배지/익명 배지 + 작성 시각, 카테고리별 내용(칭찬/발전 등 색깔 박스, 글씨가 크게 표시됨 — 뒤에서도 보이게), 이모지 반응 표시(이 화면에서는 클릭해서 반응을 추가할 수는 없고 보기만 가능)
- 발표자가 아예 없으면: "발표자가 없습니다." 텍스트만 표시
- 그 발표자에게 피드백이 없으면: "아직 피드백이 없습니다." 텍스트만 표시(화면 가운데)

## 상태별 화면
- 로딩 중: 화면 전체가 어두운 배경에 스피너만 표시.
- 그 외 로딩/에러 상태는 별도로 없음(실시간 데이터라 계속 갱신됨).

## 알아두면 좋은 것
- 이 화면은 순수 "보여주기용"이다 — 여기서 피드백을 쓰거나 반응을 남길 수 없다(관리는 "라이브 보기" 탭에서).
- "익명 적용"을 꺼서 실명을 띄우면 프로젝터 화면을 보는 모든 청중에게 작성자 이름이 노출되니, 강의실 공개 투사 시에는 켜둔 채로 쓰는 것이 기본 권장(기본값도 켜짐).
- 카드 크기 조절(열 개수)은 이 화면을 벗어나면(새로고침 등) 초기화된다 — 저장되는 설정이 아니다.
