# 성장리포트 (평가 라운드 관리)

## 진입 경로
- 사이드바 "평가" 그룹 → **성장리포트** 메뉴
- URL: `/eval` (참고용)

## 화면 구성
- 상단 `PageHeader`: 제목 "성장리포트", 부제 "발표 성장 평가 관리"
- **내 청중 평가 배너**: 접수중(`is_open=true`)인 라운드 중 나(로그인한 운영진)에게 청중평가 배정이 있는 라운드가 있으면, 화면 최상단에 카드로 항상 표시(탭과 무관하게 항상 보임). 카드에는:
  - 라운드 제목 + 유형 배지(초기/후기/통합, 색: 파랑/보라/주황)
  - "N명 평가 남음 (X/Y 완료)" 또는 "N명 모두 평가 완료" 텍스트
  - **[평가하기]**(미완료 남았을 때, 코랄색) 또는 **[확인하기]**(전부 완료, 초록색) 버튼 — 카드 전체를 눌러도 같은 동작. 클릭 시 `/eval/{라운드ID}/audience`로 이동
- 그 아래 **탭 버튼 4개**(가로 나열, 선택된 탭은 코랄 배경):
  1. **라운드 관리** — 전체 공개
  2. **배정 관리** — admin 또는 회장단만 보임
  3. **제출 현황** — admin 또는 회장단만 보임
  4. **결과 분석** — 전체 공개
  - 권한 판정: `role === "admin"` 또는 `department === "회장단"` (백엔드 `require_admin_or_chairman`과 동일 기준). 그 외 역할은 "라운드 관리"·"결과 분석" 탭만 보임
- 탭 전환 시 부드러운 페이드+슬라이드 애니메이션(0.15초)

---

## 탭 1 — 라운드 관리

### 상단
- "평가 라운드 목록" 제목
- **[+ 새 라운드]** 버튼 (admin/회장단만 보임, 우측 정렬)

### 목록이 비었을 때
- "아직 생성된 라운드가 없습니다." 텍스트만 표시

### 라운드 카드 (하나씩)
각 카드에 표시되는 정보:
- 라운드 제목
- 유형 배지: 초기(파랑) / 후기(보라) / 통합(주황)
- 상태 배지: **결과공개**(초록, `results_open=true`) / **접수중**(파랑, `is_open=true`) / **마감**(회색, 닫혔지만 결과 비공개) / **준비중**(연회색, 아직 한 번도 안 열림)
- "전체 배정: N건", "제출: N건", "생성: YYYY.MM.DD"

각 카드 우측 아이콘/버튼 (admin/회장단 여부에 따라 다름):
- 🔒/🔓 아이콘 버튼 — admin만. 자물쇠(잠김, 노란색)=접수 마감 상태, 열린자물쇠(초록)=접수 중 상태. 누르면 `is_open` 토글(접수 열기 ↔ 접수 마감). 즉시 반영, 별도 확인창 없음
- 👁/🚫👁 아이콘 버튼 — admin만. 눈(회색)=결과 비공개 상태(누르면 공개로), 슬래시눈(초록)=결과 공개 상태(누르면 비공개로). `results_open` 토글
- **[청중 평가]** 텍스트 버튼(클립보드 아이콘) — 라운드가 `is_open`일 때만, **전체 사용자**에게 보임. `/eval/{id}/audience`로 이동
- **[배정 보기]** 텍스트 버튼 — admin/회장단만. 누르면 "배정 관리" 탭으로 자동 전환되고 해당 라운드가 선택됨
- 🗑 휴지통 아이콘 — admin/회장단만. 누르면 삭제 확인 다이얼로그 오픈

### 삭제 확인 다이얼로그
- 제목: "라운드 삭제"
- 본문: `"{라운드제목}" 라운드를 삭제합니다. 모든 배정과 응답이 함께 삭제됩니다. 이 작업은 되돌릴 수 없습니다.`
- **[취소]** / **[삭제]**(빨강) 버튼

### 새 라운드 생성 다이얼로그 (2단계 마법사)
**1단계 — 기본 정보**
- **라운드 유형** 드롭다운: 초기 평가 / 후기 평가 / 통합 평가 (기본값 "초기 평가")
- **제목** 텍스트 입력 (placeholder: "예: 33기 초기 발표 평가") — 빈 값이면 "다음" 눌러도 진행 안 되고 "제목을 입력해주세요." 토스트
- **연결 세션(선택)** 드롭다운 — "세션 없음" 또는 전체 세션 목록(제목+날짜 표시). 세션을 고르면 그 세션의 분반(1/2분반) 정보가 다음 단계에서 자동 활용됨
- **[취소]** / **[다음]** 버튼

**2단계 — 청중 평가 배정 보드** (다이얼로그가 커짐, 거의 풀스크린)
- 상단 안내: "운영진별로 평가할 기수를 배정하세요. 드래그하여 이동하거나 자동 배정을 사용할 수 있습니다."
- **배정 보드**(아래 "배정 관리" 탭과 동일 컴포넌트 — 상세는 그쪽 참고). 직전 라운드에 배정이 있었으면 자동으로 미리 채워짐(빈 보드가 아님)
- 보드 하단 **[이전]** / **[생성]** 버튼 — 생성을 누르면: 라운드 생성 API 호출 → 보드에 짜여진 배정으로 청중평가 배정 저장 → 다이얼로그 닫힘
- 참고: 라운드 생성 즉시 **활성 멤버 전원에게 자기평가(SELF)가 자동 배정**됨(이 화면엔 안 보이지만 백엔드가 처리)

## 탭 2 — 배정 관리 (admin/회장단 전용)

### 상단 툴바
- **라운드** 드롭다운 — 배정을 조회/편집할 라운드 선택
- 라운드 선택 시 **[청중 평가하기]** 버튼 등장 → `/eval/{id}/audience`로 이동(관리자 본인도 평가자일 수 있으므로)
- **[배정 복사]** 드롭다운(다른 라운드가 있을 때만) — 목록에서 라운드를 고르면 그 라운드의 배정을 통째로 현재 라운드에 복사(기존 배정 대체)

### 배정 보드 (드래그앤드롭)
라운드 미선택 시 "라운드를 선택해주세요." 표시. 선택하면 보드 등장:

- **왼쪽 "기수 목록" 컬럼**: 활성 멤버 전원. 검색창(이름 검색)으로 필터링 가능. 각 멤버 카드에 배정된 평가자 수(N명) 배지, 멤버를 클릭하면 선택 상태가 되어(테두리 강조) 해당 멤버가 배정된 평가자 컬럼들이 앞으로 재정렬되고, 배정된 평가자 이름 목록이 카드 아래에 펼쳐짐
- **오른쪽 평가자별 컬럼들**(운영진 한 명당 컬럼 하나): 컬럼 제목 = 운영진 이름 + 아이디, 그 안에 배정된 기수 카드들
- **드래그 동작**:
  - 기수 목록 → 평가자 컬럼: 복사(원본은 목록에 남음, 여러 평가자에게 중복 배정 가능)
  - 평가자 컬럼 → 다른 평가자 컬럼: 이동
  - 평가자 컬럼 → 기수 목록: 제거(X 아이콘 클릭으로도 제거 가능)
  - 이미 **제출 완료**된 배정(자물쇠 아이콘 표시)은 드래그 불가·삭제 불가(잠김)
- 상단 툴바 버튼:
  - **[평가자 (N/M)]** — 드롭다운. 이번 라운드에 참여시킬 운영진 체크박스 목록, "전체 선택/전체 해제" 토글. 체크 해제하면 그 평가자 컬럼이 사라짐(단, 이미 제출된 배정이 있으면 "제출된 배정이 있는 평가자는 비활성화할 수 없습니다" 토스트로 막힘)
  - **기수당 [숫자입력] 명 평가** — 자동배정 시 각 기수를 몇 명이 평가할지 설정(기본 3)
  - **[자동 배정]**(마법봉 아이콘) — 현재 활성화된 평가자들에게 부하를 균등 분배하며 자동으로 배정. 세션에 분반 정보가 연결돼 있으면 같은 분반끼리 우선 매칭. 이미 제출된 배정은 그대로 유지하고 나머지만 채움
  - **[초기화]**(빨강) — 미제출 배정을 전부 지움(제출된 배정은 보존)
- 우측에 통계: "평가자 N명 · 기수 N명 · 배정 N건", 미배정 인원 있으면 "미배정 N명"(주황)
- 하단 **[저장]** 버튼 — 현재 보드 상태를 그대로 서버에 반영(전체 교체)

## 탭 3 — 제출 현황 (admin/회장단 전용)

- 상단 **라운드** 드롭다운
- 2단 레이아웃:
  - **왼쪽 "자기 평가(기수)" 카드**: 진행률 배지(제출/전체), 목록에 멤버 이름 + 체크(제출완료, 초록) 또는 빈 원(미제출) 아이콘, 제출한 경우 제출 날짜 표시
  - **오른쪽 "청중 평가(운영진)" 카드**: 진행률 배지, 평가자별로 그룹핑되어 각 평가자 이름 아래 담당 기수 목록과 제출 여부 표시
- 배정 없으면 "배정 없음" 텍스트

## 탭 4 — 결과 분석

- 상단 **라운드** 드롭다운(전체 사용자 이용 가능)
- **결과 비공개 멤버 패널**(접었다 펼치는 아코디언, admin/회장단만 조작 가능하나 존재 자체는 결과가 있으면 누구나 보임): "결과 비공개 멤버(결석자 등)" 클릭해서 펼치면 멤버 체크박스 목록 — 체크한 멤버는 본인에게는 결과가 안 보이게 됨(전체 공개와 별개). **[전체 해제]** / **[저장]** 버튼
- **성장 회고 모아보기**(FINAL 유형 라운드에서만 등장, 아코디언): 자기평가의 서술형 질문("유니브피티 활동을 통해 가장 크게 성장했다고 느끼는 점") 응답을 멤버별로 모아서 보여줌. 우측 **[전체 복사]** 버튼 — 전체 응답을 텍스트로 클립보드 복사(구분선 포함)
- **멤버별 결과 행 목록** — 각 행 클릭하면 펼쳐짐(아코디언):
  - 접힌 상태: 이름, 기획/디자인/스피치 3개 영역 막대그래프(통합 점수, 5점 만점), 성장 단계 배지("구조 형성"/"안정화"/"정교화"/"전달 최적화", 색 다름), 유형 배지
  - 펼친 상태(상세):
    - 성장 회고 응답(있으면, 로즈색 박스)
    - **이전 라운드와 비교 가능한 경우**(초기↔후기 페어): "PDF 다운로드" 버튼 + 초기·후기 비교 리포트 전체(레이더 차트, 영역별 점수 변화 등 — `FinalGrowthReport` 컴포넌트, 상세는 별도 조사 필요)
    - **비교 불가(단일 라운드)**: 자기평가/청중평가/통합 점수를 문항별로 상세히 보여주는 리포트(`GrowthReportContent`)

## 상태별 화면
- 로딩 중: 스피너
- 라운드 없음/데이터 없음: 안내 텍스트만
- 배정 보드 로딩 중: 스피너

## 알아두면 좋은 것
- **라운드 삭제는 되돌릴 수 없음** — 모든 배정과 제출된 응답까지 함께 사라짐
- 청중평가 배정에서 "제출 완료"된 항목은 잠겨서 못 지움 — 실수로 이미 낸 평가를 날리는 걸 방지
- "결과 공개" 토글을 켜야 기수원 포털에서도 본인 결과가 보임(꺼진 상태면 운영진만 열람 가능)
- 활성 멤버만 자동 배정 대상 — 이탈/수료 멤버는 빠짐
