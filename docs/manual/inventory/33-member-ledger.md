# 내 점수·장부

## 진입 경로
- 하단 탭 "내 점수"
- 홈 화면의 "내 점수·장부" 메뉴 카드
- URL: `/member/ledger`

## 화면 구성
위에서 아래로:
1. 디파짓(보증금) 잔액 큰 카드(코랄 그라데이션)
2. 상점/벌점/총점 3칸 카드
3. "장부 내역" 목록 + 필터 탭

## 버튼/액션 전수 목록

### 디파짓 카드 (표시 전용, 클릭 불가)
- 현재 디파짓 잔액(원 단위 큰 숫자)
- 하단에 "누적 벌금", "누적 충전" 작은 통계

### 상점/벌점/총점 카드 (표시 전용)
- 상점: 총 상점 점수 + 건수
- 벌점: 총 벌점 점수 + 건수
- 총점: 상점+벌점 합산 점수

### 장부 내역 필터 탭 (4개, 가로 나열 알약형 버튼)
| 라벨 | 클릭 시 |
|---|---|
| 전체 | 모든 내역 표시 |
| 상점 | 점수가 플러스인 내역만 |
| 벌점 | 점수가 마이너스인 내역만 |
| 벌금 | 벌금(FINE/MILESTONE_FINE) 타입 중 금액 차감분만 |

- 선택된 탭은 흰 배경+빨간 글씨로 강조.

### 장부 내역 카드 (필터링된 결과만큼 반복, 클릭 불가 — 열람 전용)
각 카드: 거래 유형 배지(상점/벌점/벌금/디파짓 충전 등, 유형별 색 다름), 날짜, 설명 텍스트(+관련 세션명), 점수 변동(+n점/-n점), 금액 변동(+n원/-n원), 우측에 "잔액 n원"(그 거래 처리 직후의 디파짓 잔액).

## 폼/입력 필드
없음(열람 전용 화면, 입력 요소 없음).

## 상태별 화면
- **로딩 중**: 숫자 칸은 "—", 목록 영역은 스피너.
- **빈 상태(전체 내역 없음)**: "아직 거래 내역이 없습니다"
- **빈 상태(필터 결과 없음)**: "해당 유형의 내역이 없습니다"

## 알아두면 좋은 것
- 이 화면은 완전히 읽기 전용이다 — 여기서 직접 무언가를 신청하거나 이의제기하는 버튼은 없다(문의는 운영진에게 별도로 해야 함, 이 화면 안에서는 불가).
- "잔액"은 각 거래 시점 기준 스냅샷이라, 목록을 위에서 아래로 읽으면 잔액이 시간순으로 어떻게 변해왔는지 확인 가능.
