# 공개 채점/투표 폼 (로그인 불필요 — 외부 심사위원·청중용)

## 진입 경로
- **로그인 전혀 필요 없음.** 운영진이 심사/채점 화면에서 만들어 배포한 링크나 QR코드로만 접근
- URL 패턴: `/s/{공개토큰}` (심사위원·순위투표용), `/s/{공개토큰}/feedback` (청중 피드백 전용 — 등수 선택 방식일 때만 별도로 존재)
- 사이드바/헤더/로그인 화면 등 앱의 다른 어떤 부분과도 연결되어 있지 않은 완전 독립 화면

## 화면 흐름 — 3단계

### 1) 첫 화면 (안내 + 이름/역할 입력)
- 심사 라운드 이름 표시
- 운영진이 남긴 **안내문**이 있으면 박스로 표시
- **이름** 입력창(필수)
- **역할 선택** (피드백 전용 링크가 아닐 때만 보임): **[🔨 심사위원 — 기준별 점수 입력]** / **[👥 청중 — N위 선택 또는 기준별 점수 입력]** 카드 버튼 중 택1
  - 피드백 전용 링크(`/feedback`)로 들어오면 역할 선택 없이 자동으로 "청중"이며, "청중 피드백 전용 링크입니다" 안내만 표시
- **소속(청중이고 소그룹이 설정된 라운드일 때만)**: 태그 버튼 목록 중 선택(필수). 이름을 입력하면 명단과 자동 매칭을 시도해서 소속을 자동으로 맞춰 채워주기도 함(수동으로 다시 고르면 그 선택이 우선됨)
- **[채점 시작]/[피드백 시작]** 버튼 — 이름 미입력 시 비활성. 이미 그 이름으로 제출한 기록이 있으면 "점수를 수정하시겠습니까?" 확인 다이얼로그가 뜸(**[취소]**/**[불러와서 수정]**) — 확인하면 이전 입력값을 그대로 불러와 이어서 수정 가능

### 2) 채점/투표 화면 (역할·설정에 따라 내용 다름)
- 상단 고정 헤더: 라운드 이름, **[제출]/[피드백 제출]** 버튼(항상 눌러서 제출 가능), 이름+역할(+소속) 표시 박스, **[다른 사람으로]** 버튼(같은 기기에서 다음 사람이 이어서 쓸 때 — 로그아웃처럼 초기화하고 이름 입력 화면으로 돌아감)
- "부"가 설정된 라운드면 부 선택 탭이 헤더 아래 나타남(피드백 전용 화면에서만 — 지금 보고 있는 부의 팀만 표시)
- 청중 피드백 전용 화면은 입력을 멈추면 1.5초 뒤 **자동으로 임시 저장**됨(화면에 "임시 저장 중…", "임시 저장됨 — 아직 제출은 안 됐어요" 등 상태 표시) — 단, 이건 진짜 제출이 아니라서 반드시 **[피드백 제출]** 버튼을 눌러야 집계에 반영됨
- **채점표(ScoreSheet) 본문**:
  - **심사위원 / 청중(기준 채점 모드)**: 심사 대상(팀)마다 영역별로 점수 입력 — 세부항목이 있으면 세부항목마다 숫자 입력(placeholder "점수"), 없으면 영역 전체에 점수 하나만 입력. 팀마다 하단에 "총평" 텍스트 입력(선택)
  - **청중(등수 선택 모드)**: 팀들 중에서 정해진 순위 개수만큼 순서를 매겨 고름(정확한 조작 방식—클릭식인지 드래그인지—은 화면 확인 필요), 본인 소속 팀은 투표 대상에서 제외될 수 있음(다동아리 모드)
  - **청중 피드백 전용 화면**: 순위 선택 없이 팀별 "피드백" 텍스트 입력칸만 나열. 설정에 따라 **전체 팀에 피드백을 작성해야만 제출 가능**(하나라도 비면 제출 시 "모든 팀에 피드백을 남겨야 제출할 수 있어요 (OO팀 등 N팀 미작성)" 에러 토스트 + 미작성 팀이 있는 부로 자동 이동)
- 하단에도 동일한 **[제출하기]** 버튼 + "제출 후에도 마감 전까지 같은 이름으로 다시 들어오면 수정할 수 있습니다" 안내

### 3) 제출 완료 화면
- 체크 아이콘 + "제출 완료" + 감사 메시지
- **[이어서 수정하기]** — 방금 낸 걸 계속 고칠 때
- **[다른 사람으로 채점하기/작성하기]** — 같은 기기를 다음 사람에게 넘길 때(입력값 전부 초기화하고 처음 화면으로)

## 에러/차단 화면
- **링크를 찾을 수 없음**(잘못된 토큰): 자물쇠 아이콘 + "링크를 찾을 수 없습니다"
- **마감됨**(`is_open=false`): 자물쇠 아이콘 + "마감되었습니다 — {라운드명} 채점이 마감되어 더 이상 제출할 수 없습니다"
- **피드백 전용 링크인데 이 라운드는 청중도 기준채점 방식인 경우**: "별도 피드백 링크가 필요 없어요 — 원래 채점 링크에서 점수와 코멘트를 함께 남겨주세요" 안내(이 상황 자체가 운영진 설정 오류일 가능성이 높음)

## 알아두면 좋은 것
- **완전 무로그인** — 링크만 있으면 누구나(같은 이름 여러 번 입력 시 "본인"으로 인식되어 수정 취급). 이름이 곧 신원 역할을 하므로 팀 내 동명이인이 있으면 헷갈릴 수 있음
- 기기(브라우저)마다 로컬로 "누구였는지" 기억해서, 링크로 재접속하면 자동으로 직전 작성 내용이 복원됨 — 공용 기기에서 다음 사람이 쓰기 전엔 꼭 **[다른 사람으로]**를 눌러야 함
- 순위 링크와 피드백 링크는 기기 복원 기록이 서로 분리되어 있음(한 기기로 순위 먼저 넣고 피드백 링크로 넘어가도 이름을 다시 입력해야 함)
- 청중 피드백은 "자동 임시저장"과 "정식 제출"이 다른 개념 — 자동저장만 되고 제출 버튼을 안 누르면 운영진 결과 화면에는 반영 안 됨
