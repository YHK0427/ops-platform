# 로그인 (운영진)

## 진입 경로
- 로그아웃 상태에서 사이트에 접속하면 자동으로 이 화면으로 이동한다.
- URL: `/login` (참고용)
- 로그인 후 이동하는 곳: 성공하면 `/dashboard`(대시보드). TOTP(2단계 인증)가 설정된 계정이면 로그인 성공 후 바로 대시보드로 가지 않고 OTP 입력 화면으로 넘어간다.

## 화면 구성
가운데 정렬된 카드 하나(최대 너비 작음, 모바일과 데스크탑 레이아웃 차이 없음 — 항상 화면 중앙에 폭 좁은 카드).

카드 안에서 상태에 따라 3가지 내용 중 하나가 보인다:
1. **로그인 입력 화면** (기본)
2. **기수 선택 화면** (같은 아이디가 여러 기수에 있을 때만)
3. **2단계 인증(OTP) 입력 화면** (TOTP 설정된 계정만)

카드 상단에는 항상 "UnivPT" 작은 라벨 + "로그인" 제목이 있다.

## 버튼/액션 전수 목록

### 1) 로그인 입력 화면
- **아이디 입력창**: 일반 텍스트 입력. 자동완성 힌트(username) 켜짐.
- **비밀번호 입력창**: 비밀번호 입력(마스킹). 자동완성 힌트(current-password) 켜짐.
- **"자동 로그인" 토글 스위치** (입력창 아래, 우측): 켜면 옆에 "로그아웃 전까지 계속 유지"라고 뜨고, 끄면 "브라우저 종료 시 로그아웃"이라고 뜬다. 기본값은 켜짐(ON) 상태.
- **"로그인" 버튼** (하단, 카드 전체 너비): 폼 제출. 로딩 중엔 버튼 안에 스피너가 돌고 글자가 "로그인 중..."으로 바뀌며 비활성화된다.

버튼을 누르면 내부적으로 다음 순서로 시도한다(사용자에게는 안 보이는 로직):
1. 먼저 "기수원 계정"인지 확인 시도
2. 아니면 "운영진 계정"으로 로그인 시도
3. 아이디가 여러 기수에 걸쳐 있어서 특정할 수 없으면 → 기수 선택 화면으로 전환
4. 아이디/비밀번호가 둘 다 아니면 → 에러 메시지 표시

### 2) 기수 선택 화면 (아이디가 여러 기수에 있을 때만 등장)
- 안내 문구: "같은 아이디가 여러 기수에 있어요. 어느 기수인가요?"
- **기수 이름 버튼들** (기수 개수만큼, 세로로 나열): 예) "33기", "34기" 등. 누르면 그 기수로 바로 로그인 시도한다(추가 확인 절차 없음, 비밀번호는 이미 입력된 것을 그대로 사용).
- **"돌아가기" 버튼** (하단, 화살표 아이콘): 기수 선택을 취소하고 처음 아이디/비밀번호 입력 화면으로 돌아간다.

### 3) 2단계 인증(OTP) 화면 (TOTP 설정된 계정만 등장)
- 방패 아이콘 + "2단계 인증" 라벨
- **OTP 코드 입력창**: 숫자만 입력 가능(자동으로 숫자 아닌 문자는 제거됨), 최대 6자리, 가운데 정렬 큰 글씨. 화면 진입 시 자동으로 포커스됨.
- **"확인" 버튼**: 코드가 정확히 6자리일 때만 활성화된다. 로딩 중엔 "확인 중..."으로 바뀜.
- **"돌아가기" 버튼**: OTP 절차를 취소하고 처음 로그인 화면으로 돌아간다.

## 폼/입력 필드 요약
| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 아이디 | 텍스트 | 필수 | |
| 비밀번호 | 비밀번호 | 필수 | |
| 자동 로그인 | 토글 | - | 기본 켜짐 |
| (기수 모호 시) 기수 선택 | 버튼 목록 | 상황부 | 여러 기수에 같은 아이디가 있을 때만 |
| OTP 코드 | 숫자 6자리 | 상황부 | TOTP 설정된 계정만 |

## 상태별 화면
- **에러(로그인 실패)**: 입력창 아래 빨간 글씨로 "아이디 또는 비밀번호가 올바르지 않습니다." 표시. 화면은 그대로 유지되고 다시 시도할 수 있다.
- **OTP 실패**: "OTP 코드가 올바르지 않습니다." 표시.
- **로딩 중**: 버튼 안 스피너 + 버튼/입력 비활성화.
- 빈 상태·데이터 없음 개념은 이 화면에는 해당 없음(항상 폼만 보임).

## 알아두면 좋은 것
- 아이디는 기수마다 별도로 관리되기 때문에, 다른 기수 사람과 아이디가 겹칠 수 있다. 이런 경우 시스템이 알아서 기수 선택 화면을 보여주므로 당황하지 않아도 된다. 대부분은 비밀번호만으로 자동 판별되어 이 화면 자체가 안 뜬다.
- "자동 로그인"을 꺼두면 브라우저(탭)를 닫을 때 자동으로 로그아웃된다. 공용 컴퓨터에서 로그인할 때는 꺼두는 것이 안전하다.
- 로그인 후 **비밀번호 변경**은 로그인 화면이 아니라, 로그인한 뒤 화면 왼쪽 사이드바 맨 아래의 "비밀번호 변경" 메뉴에서 한다(모든 페이지에서 공통으로 접근 가능). 눌러야 뜨는 창에는 현재 비밀번호·새 비밀번호(6자 이상)·새 비밀번호 확인 3칸이 있고, 현재 비밀번호가 틀리면 "현재 비밀번호가 올바르지 않습니다."라고 뜬다.
- 코드상 불명확 — 실제 화면 확인 필요: 로그인 페이지 자체는 데스크탑/모바일 레이아웃 차이가 코드상 없어 보이지만, 실제 아주 작은 화면에서 카드 여백이 어떻게 보이는지는 스크린샷으로 재확인 필요.
