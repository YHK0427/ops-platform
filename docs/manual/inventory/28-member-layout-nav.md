# 기수 포털 공통 레이아웃 (헤더 + 하단 탭 네비게이션)

이 화면은 독립된 페이지가 아니라, 로그인 후 모든 기수원 화면을 감싸는 공통 틀이다. 모바일 우선(최대 폭 제한, 하단 고정 탭바) 디자인.

## 진입 경로
- 로그인 성공 후 자동 적용됨(`/member` 이하 모든 경로에서 항상 이 헤더+하단탭이 함께 보임).

## 화면 구성
- **상단 헤더**(스크롤해도 화면 위에 고정 — sticky, 반투명 블러 배경)
  - 좌측: 작은 회색 글자로 "UnivPT {기수 이름}", 그 아래 굵은 글씨로 "안녕하세요, {이름}님"
  - 우측: 버튼 2개(아래 참조)
- **하단 탭바**(화면 맨 아래 고정, 반투명 블러 배경, 5칸 균등 분할)

## 버튼/액션 전수 목록

### 헤더 우측
- **"비밀번호" 버튼**(열쇠 아이콘 + "비밀번호" 텍스트)
  - 클릭 시: 비밀번호 변경 모달이 화면 중앙에 뜬다(아래 폼 항목 참조).
- **"로그아웃" 버튼**(로그아웃 아이콘 + "로그아웃" 텍스트)
  - 클릭 시: 즉시 로그아웃 처리(별도 확인 팝업 없음 — 바로 로그인 화면으로 튕김).

### 하단 탭바 (5개, 좌→우 순서)
| 아이콘 | 라벨 | 이동 경로 |
|---|---|---|
| 집 모양 | 홈 | `/member` (홈 화면) |
| 확성기 | 공지 | `/member/announcements` (공지 목록) |
| 막대그래프 | 리포트 | `/member/reports` (발표 성장 리포트) |
| 하트 말풍선 | 피드백 | `/member/feedback` (실시간 피드백 목록) |
| 지갑 | 내 점수 | `/member/ledger` (내 장부) |

- 현재 있는 탭은 rose색으로 강조 표시, 나머지는 회색.
- "홈" 탭만 정확히 `/member` 경로일 때만 활성 표시(`end: true`), 나머지는 하위 경로에서도 활성 유지(`end: false`) — 예: 공지 상세 화면(`/member/announcements/:id`)에서도 "공지" 탭이 계속 강조돼 있음.

## 폼/입력 필드 (비밀번호 변경 모달)
| 필드 | 타입 | 필수 | 검증 규칙 |
|---|---|---|---|
| 현재 비밀번호 | password | 예 | 서버에서 틀리면 "현재 비밀번호가 올바르지 않습니다." |
| 새 비밀번호 | password | 예 | 6자 이상 아니면 "새 비밀번호는 6자 이상이어야 합니다." |
| 새 비밀번호 확인 | password | 예 | 위 새 비밀번호와 다르면 "새 비밀번호가 일치하지 않습니다." |

- 모달 상단 "X" 버튼 또는 모달 바깥 어두운 배경 클릭 시 닫힘(입력값 사라짐).
- **"변경하기" 버튼**(모달 하단, 전체 폭)
  - 검증 통과 후 클릭(또는 Enter): 서버에 변경 요청.
  - 성공 시: 초록 토스트 "비밀번호가 변경되었습니다." + 모달 자동 닫힘.
  - 실패 시: 모달 안에 빨간 에러 문구, 모달은 안 닫힘.

## 상태별 화면
- 별도 로딩/빈 상태 없음(레이아웃 자체는 항상 즉시 렌더). 모달 제출 중엔 "변경하기" 버튼이 스피너로 바뀌고 비활성화.

## 알아두면 좋은 것
- 로그아웃은 확인 절차 없이 즉시 실행됨 — 실수로 누르면 바로 로그아웃.
- 헤더의 "{기수 이름}"과 "{이름}"은 로그인한 계정 정보에서 그대로 표시되는 것이라 개인화돼 있음.
- 이 레이아웃은 모바일 폭(`max-w-lg`)에 맞춰 가운데 정렬되므로, 데스크탑 큰 화면에서 봐도 실제 내용은 좁은 폭 안에서만 표시된다(양옆 여백).
