# 개발자 호출

## 진입 경로
- 사이드바 "소통" 섹션 → **"개발자 호출"** 메뉴(렌치 아이콘)
- **운영자(manager) 이상만 이 메뉴가 보인다** — viewer, scoring_only 계정은 사이드바에 아예 안 뜨고, 접근해도 서버가 막는다.
- URL: `/dev-feedback`

## 화면 구성
- 상단: 제목 "개발자 호출" + 부제 "버그든 뭐든 대충 적어두면 개발자가 기분 내키면 고쳐줌."
- 본문에 카드 2개(세로로 나열):
  1. **요청 작성 카드**
  2. **최근 요청 목록 카드**

### 카드 1: 수정 요청 / 건의사항 (작성)
- 안내문: "그냥 대충 요청해도 됩니다."
- **내용 입력창**(여러 줄 textarea, 최대 2000자, 필수) — placeholder 예시: "출석 탭에서 버튼 누르면 튕겨요 / 이런 기능 있었으면 좋겠어요..."
- **"요청하기" 버튼**(종이비행기 아이콘) — 내용이 비어있으면 비활성화. 전송 중엔 "요청하는 중..."으로 바뀜.

### 카드 2: 최근 요청 (목록)
- 제목 옆에 "(전체 기수)" 또는 "(우리 기수만)"이 붙는데, **이건 로그인한 계정이 담당 개발자 본인인지에 따라 자동으로 결정**된다(일반 운영진에게는 "(우리 기수만)"으로 보여 다른 기수 요청은 안 보임).
- 부제: "같은 걸 또 보내기 전에 한 번 확인해보세요."
- 요청 목록: 각 항목에 작성자 이름 + 상대 시각("N분 전" 등) + 요청 내용
  - 개발자가 답변을 남긴 요청은 내용 아래 들여쓰기 된 회신 화살표(↳) 아이콘과 함께 답변 내용이 표시됨.
  - **답변이 아직 없는 요청에 한해서, 담당 개발자 계정으로 로그인했을 때만** 그 요청 바로 아래에 답변 작성창(텍스트 입력 + "답변 등록" 버튼)이 나타난다. 일반 운영진에게는 답변 작성창 자체가 보이지 않는다.
- 목록이 비어있으면: "아직 요청이 없습니다."
- 불러오는 중: "불러오는 중..."

## 폼/입력 필드 요약
| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 요청 내용 | textarea(최대 2000자) | 필수 | |
| (개발자 전용) 답변 내용 | textarea(최대 2000자) | 필수(제출 시) | 담당 개발자 계정에게만 노출 |

## 알아두면 좋은 것
- 이 게시판은 같은 기수 운영진끼리는 서로 다 보인다(중복 신고 방지 목적) — 다른 기수 운영진에게는 안 보인다. 담당 개발자 계정만 전체 기수를 다 볼 수 있다.
- 한 번 등록한 요청은 화면상 수정/삭제 버튼이 없다 — 잘못 보냈으면 새로 다시 작성해야 한다.
- 답변이 달리면 답변 작성창이 사라진다(한 요청당 답변은 한 번만 가능한 구조로 보임 — 코드상 답변 있으면 ReplyBox 자체가 안 뜸).
