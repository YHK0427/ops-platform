# 공지/알림 (운영진 화면)

## 진입 경로
- 사이드바 맨 위쪽 "공지/알림" 메뉴(확성기 아이콘)
- URL: `/announcements`

## 화면 구성
- 상단: 제목 "공지/알림" + 부제 "기수원에게 공지를 올리고 푸시 알림을 보냅니다"
- 제목 우측 버튼 3개(왼쪽부터):
  1. **"알림 받기" / "알림 끄기" 토글 버튼**(종 아이콘) — 운영진 본인이 웹 푸시 알림을 받을지 켜고 끄는 버튼(공지 작성 기능과 무관, 내가 알림 받을지에 대한 설정).
  2. **"빠른 알림" 버튼**(종 아이콘) — 공지 게시글 없이 즉석 알림만 보내는 창을 연다.
  3. **"새 공지" 버튼**(+아이콘) — 공지 작성 창(오른쪽에서 슬라이드로 열림)을 연다.
- 본문: 공지 카드 그리드(데스크탑 최대 3열, 화면 좁아지면 1~2열)
  - 공지가 없으면: "아직 작성한 공지가 없습니다"
  - 불러오는 중이면: "불러오는 중…"

### 공지 카드 하나에 들어있는 것
- 제목(누르면 전체 보기 모달 열림), 푸시를 보낸 공지면 "푸시발송" 초록 배지
- 작성일시 · 대상(예: "기수원", "운영진", "기수 전체" 등) · 작성자
- **수정(연필) / 삭제(휴지통) 아이콘 버튼** (우측 상단)
- 본문 미리보기(최대 몇 줄, 그 밑은 흐림 처리로 가려짐) — 클릭하면 전체 보기
- 해시태그 칩들(있으면)
- 하단: **"전체 보기 →" 링크** + 이모지 반응 요약(있으면만 표시, 이 카드에서는 클릭 안 되는 보기 전용)

## 새 공지 작성/수정 창 (오른쪽 슬라이드 패널)
| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 제목 | 텍스트(최대 200자) | 필수 | |
| 본문 | 리치 에디터 | - | 굵게/이미지/링크카드/파일첨부/유튜브 등 지원(에디터 세부 기능은 별도 조사 필요 — RichEditor 컴포넌트) |
| 해시태그 | 태그 입력창 | - | 입력 후 Enter나 쉼표로 추가, 최대 10개, 태그 앞 #는 자동 처리, 각 태그 옆 X로 삭제 |
| 대상 | 버튼 4개 중 택1 | 필수 | "기수 전체(기수원+운영진)" / "기수원" / "운영진" / "특정 멤버" |
| (대상="특정 멤버"일 때) 멤버 검색+체크 | 검색창+목록 | 최소 1명 | 이름 검색 후 체크박스로 여러 명 선택, 하단에 "N명 선택됨" |
| 작성과 동시에 푸시 알림 보내기 | 체크박스 | - | **새 공지 작성 시에만 보임**(기본 켜짐). 수정할 때는 이 체크박스 대신 "※ 수정 시에는 푸시가 다시 발송되지 않습니다." 안내문으로 바뀜. |

- 창 왼쪽 아래: 자동 저장 상태 표시("자동 저장됨 · N분 전") — **새 공지 작성 중에만** 0.8초마다 자동으로 브라우저에 임시저장됨.
- 만약 이전에 쓰다 만 임시저장 글이 있으면, 창을 열 때 상단에 노란 배너 "임시저장된 글이 있어요 (N분 전)" + **"이어서 쓰기"** / **"새로 작성"** 버튼이 뜬다.
- 하단 버튼: **"취소"** / **"등록"**(신규, 푸시 체크 시 "등록 + 푸시") / **"수정"**(수정 모드)
- 제목이 비어있거나(대상이 "특정 멤버"인데 아무도 선택 안 했으면) 저장 시 에러 토스트가 뜨고 저장되지 않는다.
- 저장 성공 시 토스트 메시지: 신규+푸시 "공지를 등록하고 푸시를 보냈습니다 🔔" / 신규 "공지를 등록했습니다" / 수정 "수정했습니다"

## 공지 전체 보기 모달
카드 제목이나 "전체 보기" 클릭 시 뜨는 모달.
- 제목 + 푸시발송 배지 + 작성일시/대상/작성자 + 해시태그
- 본문 전체(리치 텍스트 그대로 렌더링)
- **이모지 반응 바** — "이 공지에 반응 남기기" 안내 아래, 클릭해서 반응 추가/취소 가능(👍❤️🔥👏🎉🥹👀 7종)
- **운영진 댓글 영역**: 댓글 목록(작성자 아바타 원+이름+운영진 배지+시각+내용, 각 댓글에 삭제 아이콘) + 댓글 없으면 "아직 댓글이 없어요" + 하단 댓글 입력창+전송 버튼
- 하단: **"삭제"** / **"수정"** 버튼

## 빠른 알림 보내기 모달
공지 게시글로 남기지 않고 즉시 푸시만 보내는 기능(예: "오늘 세션 30분 늦춰집니다").
| 필드 | 타입 | 필수 |
|---|---|---|
| 알림 제목 | 텍스트(최대 120자) | 필수 |
| 알림 내용 | textarea(최대 300자) | 필수 |
| 대상 | 위와 동일한 4버튼 + 멤버 선택 | 필수 |

**"발송" 버튼**(종이비행기 아이콘) 누르면 즉시 발송. 성공 시 "N개 기기로 알림을 보냈습니다" 토스트.

## 공지 삭제
카드나 모달의 삭제 버튼 → 브라우저 기본 확인창("이 공지를 삭제할까요?") → 확인 시 삭제, "삭제했습니다" 토스트.

## 상태별 화면
- 로딩 중: "불러오는 중…"
- 목록 불러오기 실패: "공지 목록을 불러오지 못했습니다" 에러 토스트
- 저장/삭제 실패 시 각각 에러 토스트("저장에 실패했습니다" 등)

## 알아두면 좋은 것
- "알림 받기" 토글(상단)과 "작성과 동시에 푸시 알림 보내기" 체크박스(작성 창 안)는 서로 다른 기능이다 — 하나는 "나(운영진)에게 오는 알림"이고, 다른 하나는 "이 공지를 다른 사람들에게 푸시로 보낼지"이다.
- 공지 삭제는 되돌릴 수 없다.
- 수정한 공지는 푸시가 다시 나가지 않는다 — 이미 공지된 내용을 고쳐도 조용히 반영될 뿐, 재알림하려면 "빠른 알림"을 따로 보내야 한다.
- 새 공지 작성 중 창을 실수로 닫아도 0.8초 간격으로 자동 저장되므로 다음에 "새 공지"를 열면 이어서 쓸 수 있다(단, "이어서 쓰기"를 선택해야 함).
- 코드상 불명확 — 실제 화면 확인 필요: 리치 에디터(RichEditor)의 정확한 툴바 버튼 구성(이미지 업로드, 링크 미리보기, 파일 첨부, 유튜브 임베드는 코드에서 확인됨)은 스크린샷 단계에서 직접 열어 확인 필요.
