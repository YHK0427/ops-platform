# 실시간 피드백 (목록 + 작성/열람 보드)

## 진입 경로
- 하단 탭 "피드백" → 목록 화면(`/member/feedback`)
- 홈 화면의 "실시간 피드백" 메뉴 카드, 또는 홈의 "실시간 피드백 진행 중" 배너(열린 보드가 있을 때만)
- 목록에서 보드 카드 클릭 → 보드 화면(`/member/feedback/{보드ID}`)

## 화면 구성 — 목록
- 제목 "실시간 피드백" + 부제 "발표 피드백 보드 (진행 중 · 지난 기록)"
- 보드 카드 목록: 각 카드에 제목, (진행 중이면) 빨간 점 깜빡임 + "진행중" 배지, 주차·세션명

## 화면 구성 — 보드 화면 (작성/열람)
데스크탑과 모바일 레이아웃이 크게 다르다.
- **공통 상단 헤더**: "←" 뒤로가기, 보드 제목, (분반이 있으면) 분반 배지, 우측에 실시간 연결 상태("실시간"/"연결 중" — Wifi 아이콘)
- **모바일(작은 화면)**: 헤더 아래 발표자 이름들이 가로 스크롤 칩으로 나열(내가 발표자면 "나" 표시, 피드백 개수 숫자 표시). 칩을 눌러 발표자 전환.
- **데스크탑(큰 화면)**: 왼쪽에 발표자 목록이 세로 사이드바로 고정 표시(칩과 동일 정보).
- 본문(우측/아래): 선택한 발표자에 대한 안내문 + (본인 섹션이 아니고 보드가 열려있으면) 피드백 작성 폼 + 그 발표자에게 달린 피드백 카드 그리드

## 버튼/액션 전수 목록

### 목록 화면
- 보드 카드 전체가 버튼 — 클릭 시 해당 보드로 이동.

### 보드 화면 — 발표자 전환
- **발표자 칩/목록 항목**(발표자 수만큼) — 클릭 시 그 발표자 섹션으로 전환. 본인 이름 옆엔 "나" 표시.
- 발표자가 한 명도 지정 안 됐으면 "발표자가 아직 지정되지 않았습니다." 문구만 표시(데스크탑 사이드바 기준).

### 피드백 작성 폼 (본인이 아닌 다른 발표자를 선택했고, 보드가 열려 있을 때만 표시)
- 보드 카테고리 개수만큼(예: 칭찬/발전/인상깊은 점) **여러 줄 텍스트 입력창**이 나열됨. 각 칸은 최대 1000자, 최소 하나 이상 채워야 등록 가능.
- **"익명으로 작성" 체크박스**(기본 체크됨) — 체크 해제 시 실명으로 등록.
- **"등록" 버튼**
  - 최소 한 카테고리 이상 입력해야 활성화.
  - 클릭 시: 채워진 항목들만 하나의 피드백 게시물로 등록. 등록 중엔 스피너로 바뀜.
  - 등록 후 입력창은 비워짐(같은 발표자에게 계속 남길 수 있음).
- 보드가 마감됐으면(운영진이 닫음) 이 작성 폼 자체가 안 보이고, 대신 상단에 "피드백이 마감되었습니다. (읽기 전용)" 안내 박스가 표시됨.
- 본인 섹션("내가 받은 피드백")에서는 애초에 작성 폼이 안 보임(자기 자신에게 피드백을 남길 수 없음).

### 피드백 카드 (발표자별로 달린 피드백 하나하나)
- 작성자 이름(또는 "익명") + 작성 시각 표시.
- **연필(수정) 아이콘 버튼** — 본인이 쓴 글이고 보드가 아직 열려 있을 때만 표시.
  - 클릭 시 카드가 편집 모드로 바뀌어 카테고리별 텍스트를 다시 수정할 수 있음.
  - 편집 모드에서 **"취소" 버튼**(되돌리기) / **"저장" 버튼**(적어도 한 칸 채워야 활성화, 저장 중 스피너).
- 카드 본문: 카테고리별 라벨 배지 + 내용.
- **이모지 반응 바**(카드 하단): 이미 달린 반응은 칩(숫자 포함)으로 표시, 본인이 누른 반응은 강조색. 칩을 다시 누르면 취소.
  - **"+😊" 버튼**: 클릭 시 이모지 20종 팔레트 팝업(👍❤️👏🔥🎉😮😂🥹🥺😍🤩💯🙌💪🙏✨⭐🤔👀🫶). 하나 고르면 반응 추가.
  - 보드가 마감되면 반응 버튼 자체가 비활성화(누를 수 없음, 기존 반응 숫자만 보임).
- **"댓글" 토글 버튼**(말풍선 아이콘 + 댓글 개수)
  - 클릭 시 그 카드 아래로 댓글 목록 + 입력창이 펼쳐짐/접힘.
  - 댓글 목록: 작성자 이름(또는 "익명"), 운영진이 쓴 댓글엔 "운영진" 배지, 내용. 본인 댓글에만 삭제(휴지통) 버튼.
  - 댓글 입력창 + **"익명" 토글 버튼**(눌러서 켜고 끔, 기본 켜짐) + **전송 버튼**(종이비행기, Enter로도 전송). 최대 500자.
  - 보드가 마감되면 댓글 입력창도 안 보임(목록만 열람 가능).

## 폼/입력 필드 정리
| 필드 | 위치 | 필수 | 비고 |
|---|---|---|---|
| 카테고리별 피드백 내용 | 작성 폼 | 최소 1개 이상 | 각 최대 1000자 |
| 익명 여부(작성) | 작성 폼 체크박스 | - | 기본 체크(익명) |
| 댓글 내용 | 댓글창 | 예 | 최대 500자 |
| 익명 여부(댓글) | 댓글창 토글 | - | 기본 켜짐(익명) |

## 상태별 화면
- **로딩 중**: 화면 전체 가운데 스피너.
- **빈 상태(목록)**: "아직 피드백 보드가 없습니다."
- **빈 상태(카드 없음)**: 본인 섹션이면 "아직 받은 피드백이 없습니다.", 남에게 남기는 섹션이면 "아직 피드백이 없습니다. 첫 번째로 남겨보세요!"
- **마감 상태**: 상단 잠금 아이콘 안내 박스, 작성 폼과 댓글 입력창이 숨겨지고 반응 버튼도 비활성화(전체가 읽기 전용).

## 알아두면 좋은 것
- **"익명으로 작성"은 진짜로 실명이 서버에 저장 안 되는 게 아니라, 다른 기수원에게는 별명(닉네임)으로만 보이고 운영진에게는 실명이 보이는 구조** — 사용설명서에는 "완전 무기명"이 아니라 "동료에게는 익명, 운영진은 모더레이션을 위해 실명 확인 가능"이라고 정확히 설명해야 함(코드 검토 필요, `31-member-reports.md`가 아니라 백엔드 라우터 검토 필요 — 이 fork 범위 밖 파일이므로 **코드상 확정은 다른 구역 조사 참고**, 다만 UI 문구("동료에게 익명"이라는 표현)로 미루어 이 해석이 맞을 가능성 높음).
- 진행 중인 피드백은 실시간(WebSocket)으로 갱신되므로, 다른 사람이 남긴 피드백이 새로고침 없이 바로 보임 — 화면 우측 상단 "실시간"/"연결 중" 표시로 연결 상태 확인 가능.
- 자기 자신에게는 피드백을 남길 수 없고, 받은 피드백만 열람 가능.
- 댓글의 익명 여부는 피드백 본문의 익명 여부와 **별개로 매번 다시 선택**한다(피드백은 익명으로 남기고 댓글은 실명으로 남기는 것도 가능).
