# 장부 (기수시점)

## 진입 경로
- 사이드바 "**장부(기수시점)**" (책 아이콘) — 모든 운영진(admin/manager/viewer)에게 보임.
- 멤버 상세에서 특정 항목 확인 후 전체 흐름을 보고 싶을 때도 여기로 옴(직접 링크는 없음, 사이드바로 이동).
- URL: `/ledger`

## 화면 구성
- 상단: "장부" 제목 + "입출금 및 승점 내역 관리" 부제 + 우측 액션 버튼 4개
- 필터 카드(검색창 + 멤버/유형/세션 드롭다운 3개)
- **데스크탑**: 표(날짜/멤버/세션/유형/설명/금액/점수/잔액/삭제아이콘)
- **모바일**: 카드 리스트
- 하단: 페이지네이션(이전/다음)

## 버튼/액션 전수 목록

### 상단 우측 액션 버튼 (왼쪽부터)
1. **"현황 이미지"** (보라색, 카메라 아이콘) — 클릭 시 "주간 현황 이미지" 다이얼로그가 열림(아래 참조) — 장부 데이터를 JPG 이미지로 캡처해서 다운로드하는 기능(주로 공지/보고용)
2. **"Excel 내보내기"** (초록색) — 클릭 즉시 매칭 확인 후:
   - 문제 없으면 바로 엑셀 파일 다운로드
   - 매칭 안 되는 상점 항목이 있으면 "엑셀에 매칭되지 않는 상점" 다이얼로그가 열림(아래 참조)
3. **"벌점/벌금 부여"** (빨간 테두리, 경고 아이콘) — "벌점 및 벌금 부여" 다이얼로그 열림(여러 멤버 대상 일괄, 아래 참조)
4. **"상점 부여"** (초록 배경) — "상점 부여" 다이얼로그 열림(멤버 상세와 동일한 컴포넌트, 이 화면에서는 멤버를 직접 선택해야 함)

### 필터 카드
- **검색창**("멤버명·설명 검색...") — 입력 후 0.3초 뒤 자동 검색(디바운스), 검색어 바뀌면 1페이지로 리셋
- **멤버 필터** 드롭다운 — "전체 멤버" 또는 특정 멤버 하나 선택(비활성 멤버도 목록에 포함됨 — 과거 기록 조회 위해)
- **유형 필터** 드롭다운 — "전체 유형" 또는 8가지 유형 중 하나(벌금/누적벌점벌금/디파짓충전/디파짓차감/디파짓환급/디파짓몰수/상점/기타조정)
- **세션 필터** 드롭다운 — "전체 세션" 또는 특정 세션(최근 주차부터 정렬)
- 필터 바뀌면 전부 1페이지로 자동 리셋됨

### 목록 각 행
- **설명 옆 연필 아이콘** — "장부 항목 수정" 다이얼로그(아래 참조) — **유형까지 자유롭게 바꿀 수 있는 가장 강력한 수정 기능**(멤버 상세의 인라인 수정은 금액·사유만 가능한데, 여기는 유형/금액/점수/사유/세션 전부 수정 가능)
- **행 끝 휴지통 아이콘**(마우스 올리면 나타남) — 확인 다이얼로그 후 삭제. "이 항목을 삭제하면 멤버의 잔액과 점수가 역전됩니다." — **되돌릴 수 없는 파괴적 액션**
- 누적벌점 벌금(MILESTONE_FINE) 미납 항목엔 "미납 — 납부 확인 필요" 배지 + **"납부 확인"** 버튼(확인창 후 납부완료 처리, 멤버 상세와 동일 기능)

### 페이지네이션
- **"이전"** / **"다음"** 버튼 — 페이지당 50건, 마지막 페이지면 "(마지막)" 표시, 다음 버튼은 결과가 50건 미만이면 비활성화

## 폼/입력 필드

### "장부 항목 수정" 다이얼로그
- **유형** 드롭다운(8종 전체 중 자유 변경 가능)
- **금액** 숫자(음수 가능)
- **점수** 숫자(음수 가능)
- **설명** 텍스트(필수)
- **세션** 드롭다운(선택)
- 버튼: **"취소"** / **"저장"**(설명 비어있으면 비활성, 처리 중 스피너) — "금액/점수 변경 시 멤버 잔액이 즉시 반영됩니다" 안내문 있음

### "벌점 및 벌금 부여" 다이얼로그 (여러 멤버 일괄)
- 상단 **탭 전환**: "벌점 프리셋" / "수동 거래"
- **벌점 프리셋 탭**: GivePenaltyDialog와 동일한 16개 프리셋 + 벌점/디파짓차감 직접입력
- **수동 거래 탭**: 유형 드롭다운(벌금(-) / 디파짓 충전(+) / 디파짓 차감(-) / 디파짓 환급(+) / 기타 조정) + 금액 + 점수(변동 없으면 0)
- 공통: **사유**(필수), **세션**(선택), **멤버 선택**(검색창 + 체크박스 목록, 여러 명 동시 선택 가능 — "멤버 선택 (N명)"으로 카운트 표시)
- 미리보기: "N명 × -점수 '사유'" 형태
- 제출 버튼: 프리셋 모드는 **"벌점/벌금 부여"**, 수동 모드는 **"거래 생성"**(처리 중 "처리 중 (N명)...") — 멤버 미선택/사유 없음/점수·금액 둘 다 0이면 비활성. **선택한 멤버 전원에게 동시에 적용되는 일괄 액션**이니 멤버 선택을 잘 확인해야 함

### "상점 부여" 다이얼로그 (이 화면에서 열면 멤버 직접 선택 필요)
- 03-member-detail.md의 "상점 부여" 다이얼로그와 동일하나, `preselectedMemberId`가 없어 **"멤버 선택 (N명)"** 섹션이 나타나 여러 멤버에게 동시 부여 가능

### "주간 현황 이미지" 다이얼로그
- 탭 3개: **현황판** / **출석부** / **상세 내역**
- **주차 선택** 드롭다운("전체 주차" 또는 특정 주차)
- **라이트/다크** 토글 버튼(이미지 배경 테마)
- **"[탭이름] 다운로드"** 버튼 — 현재 보고 있는 탭만 JPG로 다운로드
- **"3장 모두 다운로드"** 버튼 — 3개 탭 전부 한 번에 다운로드
- 본문에 실시간 미리보기 이미지가 표시됨

### "엑셀에 매칭되지 않는 상점" 다이얼로그 (Excel 내보내기 시 조건부)
- 매칭 안 된 상점 항목마다: 멤버명 + 점수 + 현재 사유 텍스트 + **프리셋 선택** 드롭다운(13개 표준 사유 중 하나로 교정 가능)
- 버튼: **"그대로 다운로드"**(수정 없이 진행, 해당 항목은 엑셀에서 누락될 수 있음) / **"수정 후 다운로드"**(선택한 프리셋으로 사유를 실제로 고친 뒤 다운로드 — 몇 건 수정했는지 버튼 라벨에 표시됨)

## 상태별 화면
- **로딩 중**: 표는 회색 스켈레톤 바(5줄), 모바일은 회색 블록 카드 5개
- **데이터 없음**: "표시할 내역이 없습니다."
- **에러**: 코드상 명시적 에러 UI 없음(체크/다운로드 실패는 토스트 "Excel 체크 실패" 등으로만 안내) — 실제 화면 확인 필요.

## 알아두면 좋은 것
- 이 화면의 "장부 항목 수정"은 **유형 자체를 바꿀 수 있는** 유일한 곳이다(멤버 상세 페이지의 인라인 수정은 금액·사유만 가능) — 잘못 등록된 항목의 종류까지 고치려면 여기로 와야 함.
- "벌점/벌금 부여"·"상점 부여" 모두 이 화면에서는 **여러 멤버에게 한 번에** 적용되는 일괄 작업이라, 실수로 멤버를 잘못 선택하면 여러 명에게 동시에 반영된다 — 제출 전 "N명" 카운트와 미리보기를 꼭 확인해야 함.
- 삭제는 잔액·점수를 역산해서 되돌리는 방식이라 신중해야 하는 파괴적 액션.
- 검색은 300ms 디바운스가 걸려있어 타이핑 중엔 바로 반응하지 않고 약간 딜레이 후 결과가 갱신된다.
