# 팀 빌딩 도우미 — 보드 목록

## 진입 경로
- 사이드바 "세션" 그룹 → **팀 빌딩** 메뉴
- URL: `/team-building`

## 화면 구성
- 상단 `PageHeader`: 제목 "팀 빌딩", 부제 "과거 팀세션과 겹치지 않게 팀을 짜는 도우미 — 리슨업·BP 등 보드별로 관리", 우측 **[+ 새 팀빌딩]** 버튼
- 보드 없으면: 아이콘 + "아직 팀빌딩 보드가 없어요. **새 팀빌딩**으로 만들어보세요. (예: 리슨업 팀 빌딩, BP 팀 빌딩)"
- 보드 있으면: 카드 그리드(데스크탑 2열) — 보드 이름, "수정 YYYY.MM.DD"(최종 수정일), hover 시 나타나는 🗑 삭제 버튼(브라우저 confirm창으로 재확인), 카드 클릭 시 해당 보드 편집 화면으로 이동

## 새 팀빌딩 보드 만들기 다이얼로그
- **보드 이름** 입력(필수, placeholder "예: BP 팀 빌딩")
- **[만들기]** 버튼 — 만들면 곧바로 편집 화면(`/team-building/{id}`)으로 이동

## 알아두면 좋은 것
- 보드는 특정 세션에 종속되지 않는 독립 도구 — 여러 개 만들어서 목적별로 구분 가능(리슨업용, BP용 등)
- 삭제하면 그 보드의 배정 데이터가 전부 사라짐(되돌릴 수 없음)
