# 전체 세션 (세션 목록)

## 진입 경로
- 사이드바 "세션" 섹션 → "전체 세션" 메뉴
- URL: `/sessions`

## 화면 구성
- 상단: 제목 "전체 세션" + 부제 "전체 세션 목록 및 상태 관리" + 우측에 "새 세션" 버튼
- 본문: 세션 카드 그리드(데스크탑 3열 / 태블릿 2열 / 모바일 1열). 최신 날짜순 정렬
- 각 카드: N주차 배지 + 상태 배지, 세션 제목, 날짜, 개인/팀 세션 구분, (팀 세션이고 배정됐으면) N개 팀 배정됨

## 버튼/액션 전수 목록
- **"새 세션" 버튼** (상단 우측, + 아이콘): 클릭 시 `/sessions/new`(세션 생성 마법사)로 이동
- **세션 카드 전체** (클릭 가능한 카드): 카드 아무 곳이나 클릭하면 해당 세션 상세(`/sessions/{id}`)로 이동. 마우스 올리면 카드 테두리 강조 + 하단에 얇은 강조선 애니메이션
- **삭제 아이콘(휴지통, 카드 우측 상단)**: 세션 상태가 `FINALIZED`(마감 완료)가 아닐 때만 표시(마우스를 카드에 올려야 보임 — 평소엔 투명). 클릭 시 브라우저 기본 확인창(`"{세션제목}" 세션을 삭제하시겠습니까?`)이 뜨고, 확인하면 즉시 삭제(되돌리기 불가). 카드 클릭 이동은 안 되게 이벤트 전파 차단됨
- **화살표 아이콘(카드 우측 상단)**: 세션이 `FINALIZED` 상태일 때만 삭제 아이콘 대신 표시(삭제 불가능함을 암시). 클릭 기능은 없고 카드 자체가 클릭 영역
- **"첫번째 세션 생성하기" 버튼** (세션이 하나도 없을 때만 표시): `/sessions/new`로 이동

## 폼/입력 필드
없음(목록 화면).

## 상태별 화면
- 로딩 중: 카드 6개 자리에 회색 스켈레톤 박스
- 에러 시: "세션 목록을 불러오는 중 오류가 발생했습니다." (빨간 글씨, 중앙 정렬)
- 빈 상태(세션 0개): 점선 테두리 박스 안에 "등록된 세션이 없습니다." + "첫번째 세션 생성하기" 버튼

## 알아두면 좋은 것
- 세션 삭제는 **확인창 통과 즉시 실행**, 취소/복구 기능 없음(백엔드에서 되돌릴 수 없음)
- FINALIZED(정산 마감된) 세션은 삭제 버튼 자체가 안 보여서 실수로 못 지움
