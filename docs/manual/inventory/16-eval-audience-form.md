# 청중 평가 작성 화면 (운영진용)

## 진입 경로
- 성장리포트 화면의 "내 청중 평가" 배너 카드 **[평가하기]/[확인하기]** 버튼
- 성장리포트 "라운드 관리" 탭의 각 라운드 카드 **[청중 평가]** 버튼(라운드가 접수중일 때만 보임)
- "배정 관리" 탭에서 라운드 선택 시 뜨는 **[청중 평가하기]** 버튼
- URL: `/eval/{roundId}/audience` — 전체화면(사이드바 없음), 뒤로가기(←) 버튼으로 성장리포트 화면(`/eval`)으로 복귀

## 화면 구성 — 3단계

### 1) 배정 없음
청중 평가 배정이 하나도 없으면 "배정된 청중 평가가 없습니다." + **[돌아가기]** 버튼만 표시.

### 2) 인트로 화면 (첫 진입 시 항상 먼저 보임)
- 상단 헤더: ← 뒤로가기, "청중 평가" 타이틀 + 라운드 제목
- 기수 라벨 배지(예: "UnivPT 33기")
- 라운드 유형(초기/후기)에 따라 다른 안내문 — 라운드 성격, 평가 취지, 객관적으로 판단해달라는 당부 등 상당히 긴 안내 텍스트(후기는 "발표성장리포트 TF 일동" 서명 포함)
- "평가 문항 소개" 박스 — 기획/디자인/스피치 3영역, 5점 척도(1=매우 그렇지 않다 ~ 5=매우 그렇다) 설명
- **[✨ 평가 시작하기]** 버튼 — 누르면 실제 평가 폼으로 전환(인트로는 매번 다시 봐야 함, 넘어가면 다시 안 뜸—세션 내에서만)

### 3) 실제 평가 폼
- 상단 헤더: 라운드 제목 + "N/M 제출완료" 카운터
- **왼쪽 사이드바(데스크탑만, 모바일에선 숨김)**: "평가 대상" 멤버 목록 버튼들. 제출완료(초록 체크)/미제출(빈 원) 아이콘. 클릭하면 오른쪽에 그 멤버 평가 폼이 뜸. 전원 제출 완료 시 사이드바 아래에 감사 인사 박스 표시
- **모바일 전용 상단 네비게이션**: 멤버 미선택 시 "평가할 멤버를 선택하세요" + 세로 버튼 목록. 멤버 선택 후엔 ◀ 이름/진행률 ▶ 형태의 좌우 화살표 네비게이션(이전/다음 멤버로 이동, 배정 순서 기준. 첫/마지막에서는 해당 방향 화살표 비활성화)
- **오른쪽 평가 폼**(멤버 선택 시):
  - 멤버 이름 + "제출완료" 배지(이미 제출한 경우)
  - 이미 제출했던 응답이 있으면 안내 문구: "이전 제출 내역이 표시되어 있습니다. 수정 후 재제출할 수 있습니다."
  - 진행률 바(응답한 문항 수/전체 9문항)
  - **문항 9개**, 기획(3)/디자인(3)/스피치(3) 영역별로 묶여서 세로로 나열. 각 문항: 라벨 배지(예: "일관성") + 질문 전문 + **5점 라이커트 척도**(1~5 버튼, `LikertScale` 컴포넌트 — 실제 화면에서 버튼 모양·라벨 확인 필요)
  - 하단 고정(sticky) **[평가 제출하기]** 버튼 — 9문항 전부 응답해야 활성화(안 그러면 회색 비활성). 이미 제출한 멤버는 버튼 라벨이 "재제출하기"로 바뀜
  - 제출 성공 시: 자동으로 다음 미제출 멤버로 넘어가서 그 폼이 뜸(스코어 초기화). 더 이상 미제출 멤버가 없으면 **완료 축하 모달** 팝업(초록 체크 아이콘 + 감사 메시지 + **[확인]** 버튼)

## 폼/입력 필드
- 문항당 라이커트 5점 척도 1개 (필수, 미응답 시 제출 버튼 비활성 + "모든 문항에 응답해주세요." 토스트)

## 상태별 화면
- 로딩 중: 전체화면 스피너
- 배정 없음: 안내 문구 + 돌아가기 버튼

## 알아두면 좋은 것
- 인트로 화면은 화면을 새로고침하거나 다시 들어올 때마다 다시 나타남(건너뛰기 저장 안 됨)
- 이미 제출한 평가도 같은 화면에서 값 수정 후 재제출 가능(덮어쓰기, 별도 이력 안 남음)
- 한 멤버 제출 후 자동으로 다음 사람으로 넘어가므로, 순서대로 쭉 진행하면 됨 — 특정 사람만 다시 고치고 싶으면 왼쪽(모바일은 화살표)에서 직접 선택
