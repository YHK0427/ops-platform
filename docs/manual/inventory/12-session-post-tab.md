# 세션 상세 — "과제 검사" 탭 (POST)

## 진입 경로
- 세션 상세 화면 상단 탭 바에서 "과제 검사" 클릭(세션 상태가 POST 이상이어야 클릭 가능)
- URL: `/sessions/{id}/post`
- 상세 헤더/탭바/기한표시줄은 "출석" 탭 문서 참고(공통)

## 화면 구성
- 상단: "과제 검사" 제목 + "PPT, 리뷰, 피드백 제출 현황을 스캔하고 관리합니다" 부제
- 우측 **"과제 스캔" 버튼**(빨간 배경, 돋보기 아이콘): 클릭 시 네이버 카페 게시판(PPT/리뷰/피드백)을 스캔하는 백그라운드 작업 시작. "과제 스캔이 시작되었습니다" 토스트 → 아래에 진행상태 박스가 나타남(스피너→완료/실패 아이콘 + 작업 ID + 결과 요약). 스캔 진행 중엔 버튼이 "스캔 중..."으로 바뀌고 재클릭 불가
- 카드 "과제 현황" — "드롭다운으로 상태를 직접 변경할 수 있습니다" 부제

### 과제 현황 표
세션 설정에서 켜둔 과제 항목만 열로 표시(PPT 게시판 / 리뷰 / 피드백 중 활성화된 것만).

- **데스크탑**: 표 형태. 행 = 멤버(팀 세션이면 이름 옆에 팀명 표시, 이탈/수료 멤버는 상태 배지 표시), 열 = 과제 종류별 상태
- **모바일**: 멤버별 카드, 카드 안에 과제 종류별 행

**각 셀의 구성**
- 그 멤버에게 해당 과제 배정 자체가 없으면 "—"만 표시(조작 불가)
- 배정이 있으면 **상태 드롭다운**: 제출완료 / 미제출(확정) / 면제 / 미확인 — 선택하는 즉시 저장(별도 저장 버튼 없음)
- 상태 옆에 **외부 링크 아이콘**(PPT/리뷰 타입이고 게시글이 식별됐을 때만): 클릭하면 새 탭으로 네이버 카페 해당 게시글이 열림
- **피드백 항목일 때만**: 상태 아래에 작은 칩들이 추가로 나타남 — 그 멤버가 피드백을 남겨야 할 대상마다 칩 하나씩(대상 이름 또는 "본인"), 체크 아이콘(초록, 작성함)/X 아이콘(빨강, 안 씀)으로 완료 여부 표시. 실제 댓글 내용이 크롤링됐으면 말풍선 아이콘이 추가로 붙고, **그 칩을 클릭하면 팝오버**가 열려서 실제로 쓴 피드백 댓글 원문을 볼 수 있음

## 알아두면 좋은 것
- 상태 드롭다운 변경은 확인창 없이 즉시 반영됨(실수로 잘못 눌러도 바로 되돌릴 수 있음 — 다시 드롭다운에서 원래 값 선택)
- "과제 스캔"은 이미 스캔된 항목을 덮어쓸 수 있으니, 수동으로 상태를 고쳐놓은 뒤 다시 스캔을 돌리면 그 수정이 스캔 결과로 되돌아갈 수 있음(스캔 로직이 최신 크롤링 결과를 반영하기 때문)
