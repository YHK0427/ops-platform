# 멤버 상세

## 진입 경로
- **멤버** 목록 화면에서 아무 행/카드나 클릭
- **대시보드**의 "위험 인물 한눈에" 카드에서 이름 칩 클릭
- URL 패턴: `/members/{멤버ID}`

## 화면 구성
- 상단: 멤버 이름(제목) + 이메일(부제) + 우측 버튼들
- 본문(위→아래):
  1. (조건부) "받아야 할 돈" 경고 박스 — 디파짓 부족 또는 벌금 미납이 있을 때만 표시
  2. 디파짓 카드 + 총점수 카드 (2열 그리드, 모바일은 세로로 쌓임)
  3. 거래 내역(장부) — 데스크탑은 표, 모바일은 카드 리스트

## 버튼/액션 전수 목록

### 상단 헤더
- **"뒤로"** 버튼 — 멤버 목록(`/members`)으로 이동
- **"수정"** 버튼(연필 아이콘) — 클릭 시 우측에서 "멤버 수정" 패널이 열림(이름/이메일/태그 수정 — 멤버 추가 폼과 동일한 UI)
- **활성 멤버일 때**:
  - **"수료"** 버튼(초록, 학사모 아이콘) — 클릭 시 확인 다이얼로그: "OOO을(를) 수료 처리하시겠습니까? 잔여 디파짓 ₩N이 환급됩니다." → **"취소"** 또는 **"수료 확인"**(처리 중엔 "처리 중...") — 확인하면 수료 처리 후 멤버 목록으로 자동 이동
  - **"이탈 처리"** 버튼(빨강, 경고 아이콘) — 클릭 시 확인 다이얼로그: "OOO을(를) 이탈 처리하시겠습니까? 잔여 디파짓 ₩N은 금고로 귀속되며 환급되지 않습니다." → **"취소"** 또는 **"이탈 처리 확인"** — 확인하면 이탈 처리 후 멤버 목록으로 이동. **되돌릴 수 없는 것에 준하는 액션**(재활성화는 가능하지만 디파짓은 이미 금고로 귀속돼 복구 안 됨)
- **비활성(이탈/수료) 멤버일 때**: 위 두 버튼 대신 **"재활성화"** 버튼(초록) 하나만 표시 — 클릭 시 브라우저 기본 확인창("OOO을(를) 재활성화하시겠습니까?")이 뜨고 확인하면 즉시 재활성화(다이얼로그 UI가 아니라 `confirm()` 팝업이라 다른 버튼들과 스타일이 다름)

### "받아야 할 돈" 경고 박스 (조건부 표시)
- 디파짓 충전 필요액 / 누적벌점 벌금 미납액 / 총 받을 돈 3칸으로 표시
- 미납 벌금이 있으면 하단에 **"누적벌점 벌금 납부 확인 (₩N)"** 버튼(초록) — 클릭 시 브라우저 확인창("OOO님의 누적벌점 벌금 ₩N (N건) 납부를 확인 처리합니다. 금고 수입으로 반영됩니다.") → 확인하면 미납 건 전부를 납부완료 처리

### 디파짓 카드
- **"관리"** 버튼(우상단) — 클릭 시 "디파짓 관리" 다이얼로그가 열림 (아래 폼 참조)
- 잔액이 10,000원 미만이고 활성 멤버면, 카드 안에 "충전 요망" 표시 + 부족분 금액 + **인라인 입력창**(부족분이 기본값으로 미리 채워짐) + **"충전 확인"** 버튼(파랑) — 별도 다이얼로그 없이 카드 안에서 바로 충전 가능

### 총점수 카드
- **"상점 부여"** 버튼(초록) — 클릭 시 "상점 부여" 다이얼로그(아래 참조), 이 멤버로 미리 선택된 상태라 멤버 선택 UI는 안 보임
- **"벌점 부여"** 버튼(빨강) — 클릭 시 "벌점 부여" 다이얼로그(아래 참조), 역시 이 멤버 대상으로 고정
- 하단에 태그 목록 표시(수정 불가, 읽기 전용 — 태그 변경은 "수정" 버튼으로)

### 거래 내역(장부) 표/카드 — 각 행마다
- 마우스를 올리면(데스크탑) 우측에 연필 아이콘(수정)과 휴지통 아이콘(삭제)이 나타남(모바일은 항상 보임)
- **연필 아이콘** — 클릭 시 작은 팝오버가 열려 "금액(원)"과 "사유"를 바로 수정 가능, **"저장"** 버튼으로 반영
- **휴지통 아이콘** — 클릭 시 확인 다이얼로그: "이 항목을 삭제하면 멤버의 잔액과 점수가 역전됩니다. 계속하시겠습니까?" → **"취소"** 또는 **"삭제"**(빨강) — **되돌릴 수 없는 파괴적 액션**, 삭제하면 그 거래로 인한 잔액/점수 변동이 전부 취소됨
- 누적벌점 벌금(MILESTONE_FINE) 타입 항목이 미납 상태면, "미납 — 납부 확인 필요" 배지 옆에 **"납부 확인"** 버튼 — 클릭 시 확인창 후 해당 건만 납부완료 처리(위 상단 박스의 일괄 확인과 달리 건별로도 가능)

## 폼/입력 필드

### "멤버 수정" 패널
멤버 추가 시트와 동일: 이름(필수), 이메일(선택), 태그(추천 태그 토글 + 직접 입력). 제출 버튼 **"저장"**(처리 중 "저장 중...").

### "디파짓 관리" 다이얼로그
- **유형** 드롭다운: "디파짓 충전 (+)" / "디파짓 차감 (-)"
- **금액(원)** 숫자 입력(음수 불가, 부호는 유형에 따라 자동 표시)
- **사유** 텍스트(필수 — 비어있으면 제출 버튼 비활성)
- 금액을 입력하면 "변동 후 잔액" 미리보기가 바로 아래 표시됨
- 제출 버튼: 유형에 따라 **"충전"** 또는 **"차감"**(처리 중 "처리 중...") — 사유 비어있거나 금액 0이면 비활성

### "상점 부여" 다이얼로그 (멤버 상세에서 열면 대상 고정)
- **프리셋 선택** 칩들: 친바 선정팀(+1)/Listen Up 1등(+4)/Listen Up 2등(+4)/BP 1등(+4)/BP 2등(+4)/피날래 본선 진출(+3)/발전왕 선발(+4)/베스트 협력상(+1)/오프·오피(+1)/추억상자 글 작성(+1)/번개 주최 완료(+1)/번개 참석 2회(+1)/정보성 자료 공유(+1) — 누르면 점수와 사유가 자동 입력됨
- **점수** 숫자(직접 수정 가능, 프리셋 선택 해제됨)
- **사유** 텍스트(필수)
- **연결 세션** 드롭다운(선택, "세션 없음" 기본)
- 입력하면 하단에 "N명 × +점수 '사유'" 미리보기
- 제출 버튼 **"부여"**(멤버·점수·사유 다 있어야 활성화, 처리 중 스피너)

### "벌점 부여" 다이얼로그
- **유형 선택** 프리셋 16개(위 GivePenaltyDialog 목록 — 지각/조퇴/결석 각 사전·사후·사유서없음 3단계, PPT이메일 지연/미제출, 과제 미제출, 무임승차, 직접 입력) — 선택 시 점수·디파짓차감이 자동 채워지고 입력창이 잠김(직접 입력 선택 시에만 수정 가능)
- **벌점** 숫자(1 이상)
- **디파짓 차감** 숫자(0 이상, 없으면 0)
- **사유** 텍스트(필수)
- **세션** 드롭다운(선택, "세션 없음" 기본)
- 미리보기: "-N점" / "-N원"(차감 있을 때만)
- 제출 버튼 **"벌점 부여"**(빨강, 점수·사유 있어야 활성화)

## 상태별 화면
- **로딩 중**: 화면 중앙 스피너
- **멤버를 찾을 수 없음**(잘못된 ID 등): "멤버를 찾을 수 없습니다" + **"돌아가기"** 링크
- **거래 내역 없음**: "내역이 없습니다."
- **에러**: 코드상 별도 에러 UI 없음 — 실제 화면 확인 필요.

## 알아두면 좋은 것
- **이탈 처리는 디파짓을 환급하지 않고 금고로 귀속**시키지만, **수료 처리는 디파짓을 멤버에게 환급**한다 — 버튼 색(이탈=빨강/수료=초록)과 다이얼로그 문구로 구분되니 헷갈리지 않게 잘 확인해야 함.
- 장부 항목 삭제는 잔액·점수를 그대로 되돌리는(역전시키는) 동작이라 신중해야 함 — 특히 이미 다른 후속 거래가 쌓인 뒤에 옛날 항목을 지우면 계산이 꼬일 수 있음(코드상 이 경우의 안전장치는 확인 안 됨 — 실제 화면 확인 필요).
- 디파짓 환급(DEPOSIT_REFUND)·몰수(DEPOSIT_FORFEIT) 거래는 장부에서 빨간 마이너스가 아니라 보라색/노란색으로 표시된다 — 실제로는 "정상 처리"인데 손해처럼 보이지 않게 하기 위한 디자인.
- "재활성화"는 다른 버튼들과 달리 예쁜 다이얼로그가 아니라 브라우저 기본 확인창(`confirm`)으로 뜬다 — 다른 액션과 UI가 살짝 다르다는 점 참고.
