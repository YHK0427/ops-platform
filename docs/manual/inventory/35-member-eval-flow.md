# 자기평가 작성 → 완료 → 결과 열람 (3단계 흐름)

`31-member-reports.md`의 "평가하기"/"결과 보기" 버튼을 누르면 이어지는 화면들.

---

## 1단계: 자기평가 작성 (`/member/eval/{라운드ID}`)

이 화면은 평가 종류(초기 vs 후기)에 따라 안내 문구가 다르고, **후기(FINAL) 평가일 때만** 회고 작성 단계가 하나 더 추가된다. 내부적으로 3개 하위 단계(intro → reflection → questions)로 구성되며 뒤로가기 버튼으로 이전 단계로만 이동 가능(단계를 건너뛸 순 없음).

### 1-1. 소개 화면 (intro)
- 상단: "←" 뒤로가기(홈으로 이동) + "자기 평가" 제목
- 코랄 그라데이션 배경 카드: 기수 배지 + "발표 성장 리포트 · 후기 평가"(후기) 또는 "나의 발표 성장 기록"(초기) 제목 + 부제
- 안내문 카드: 평가 취지를 설명하는 긴 안내 텍스트(초기/후기 각각 다른 문구, 후기는 맨 아래 "발표성장리포트 TF 일동" 서명 포함)
- 하단 고정 버튼:
  - **"평가 시작하기"**(초기 평가일 때) — 클릭 시 바로 문항 화면(questions)으로 이동.
  - **"다음으로"**(후기 평가일 때) — 클릭 시 회고 작성 화면(reflection)으로 이동.

### 1-2. 성장 회고 작성 (reflection) — 후기 평가에서만 나타남
- 상단: "←"(소개 화면으로 되돌아감) + "나의 성장 돌아보기" 제목
- 안내 카드 + 질문: "Q. 유니브피티 활동을 통해, 가장 크게 성장했다고 느끼는 점은 무엇인가요? *"(빨간 별표 = 필수)
- **여러 줄 텍스트 입력창**(자유 서술, 글자수 실시간 표시)
- 하단 고정 버튼: **"평가 시작하기"** / 아직 안 썼으면 버튼 문구가 "성장 회고를 입력해 주세요"로 바뀌고 비활성화. 한 글자라도 입력해야 활성화됨(공백만 있으면 비활성 유지).

### 1-3. 문항 응답 (questions)
- 상단: "←"(이전 단계로) + "자기 평가" 제목 + "n/전체 문항 완료" 진행 상황 + (이미 제출했으면) 초록 "제출 완료" 배지. 그 아래 진행률 바(가로 게이지).
- 이미 제출된 상태면 본문 맨 위에 "제출 완료 — 수정이 필요하면 변경 후 재제출할 수 있습니다" 안내 박스.
- "평가 문항 소개" 안내 카드: 기획/디자인/스피치 3개 영역으로 구성됨을 설명.
- "평가 기준" 범례 카드: 1점(매우 그렇지 않다) ~ 5점(매우 그렇다) 라벨 설명.
- **문항 목록**: 영역별(기획/디자인/스피치)로 묶여서 표시, 각 영역 헤더에 그 영역 문항 중 몇 개 답했는지(n/전체) 표시.
  - 각 문항 카드: 문항 텍스트 + **1~5점 원형 버튼 5개**(가로 나열, 각 버튼에 마우스 올리면 점수 설명 툴팁). 하나 선택하면 그 버튼이 색칠되고 이전 선택은 해제(단일 선택).
- 하단 고정 **제출 버튼**:
  - 안 채운 문항이 있으면: "n개 문항이 남았습니다"로 비활성화 표시.
  - (후기 평가인데 회고를 안 썼으면) "성장 회고 입력이 필요합니다" — 클릭 시 회고 작성 화면으로 강제 이동.
  - 다 채웠으면: 처음 제출은 "평가 제출하기", 이미 제출한 적 있으면 "재제출하기".
  - 제출 중엔 스피너 + "제출 중...".
  - 제출 성공(첫 제출)하면 완료 화면(`/member/eval/{라운드ID}/complete`)으로 이동. 재제출(이미 제출했던 경우)은 완료 화면으로 안 넘어가고 그 자리에 남음(제출 완료 배지만 유지).
  - 실패 시 버튼 아래 "제출에 실패했습니다. 다시 시도해주세요." 문구.

### 폼/입력 필드 정리
| 필드 | 화면 | 타입 | 필수 |
|---|---|---|---|
| 성장 회고 | reflection(후기만) | 여러 줄 텍스트 | 예 |
| 문항별 점수 | questions | 1~5점 버튼 선택 | 예(전 문항) |

---

## 2단계: 완료 화면 (`/member/eval/{라운드ID}/complete`)
- 첫 제출 성공 시에만 자동으로 도달(재제출 시엔 안 감).
- 체크마크 애니메이션 + "평가가 완료되었습니다!" + 감사 인사 문구.
- **"홈으로 돌아가기" 버튼**(유일한 버튼) — 클릭 시 `/member` 홈으로 이동.

---

## 3단계: 결과 열람 (`/member/eval/{라운드ID}/result`)

### 상태 1 — 아직 결과 비공개
- 자물쇠 아이콘 + "아직 결과가 공개되지 않았습니다" + "운영진이 결과를 공개하면 확인하실 수 있습니다".
- 상단 "←" 버튼으로 홈으로 돌아가기만 가능, 그 외 액션 없음.

### 상태 2 — 후기(비교) 결과의 인트로 화면 (초기·후기 둘 다 있는 경우만)
- 코랄 그라데이션 카드: "{이름}님의 발표 성장 리포트" + 기수 슬로건
- 안내 문구 카드
- **"내 성장 리포트 확인하기" 버튼**(하단 고정) — 클릭 시 실제 리포트 화면으로 전환.
- 상단 "←"는 리포트 목록(`/member/reports`)으로 이동.

### 상태 3 — 실제 리포트 화면
- 상단: "←"(홈으로) + "발표 성장 리포트" 제목 + **"PDF 다운로드" 버튼**(다운로드 아이콘)
  - 클릭 시: 리포트를 이미지로 캡처해 PDF 파일로 생성 후 브라우저에 다운로드(파일명 "{이름}_발표 성장 리포트.pdf"). 생성 중엔 버튼이 스피너+"생성 중..."으로 바뀌고 비활성화. 초기 리포트는 2페이지, 초기+후기 비교 리포트는 표지 포함 3페이지 PDF.
- 본문: 발표 역량 방사형(레이더) 그래프, 영역별(기획/디자인/스피치) 점수와 단계 해석, 자기평가 vs 청중평가 비교, 발표 유형(균형형/강점 집중형/보완점 명확형) 해석, 성장 PLAN(영역별 낮은 문항 기반 맞춤 피드백) 등 — 순수 정보 열람 화면으로 이 안에는 클릭 가능한 요소가 없음(PDF 다운로드 버튼 제외).

## 알아두면 좋은 것
- 후기 평가는 회고를 반드시 먼저 써야 문항 응답으로 넘어갈 수 있다 — 순서를 안 지키면 제출 버튼이 회고 작성 화면으로 강제로 돌려보낸다.
- 재제출은 언제든 가능하지만, 완료 축하 화면은 **최초 제출 때만** 보여진다.
- 결과는 운영진이 "공개" 처리해야만 볼 수 있다 — 평가를 제출했다고 바로 결과가 보이는 게 아님.
- PDF 다운로드는 실제로 화면을 이미지로 찍어서 만드는 방식이라 생성에 몇 초 걸릴 수 있다.
