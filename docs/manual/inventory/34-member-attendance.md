## 화면 구성
- 상단: 달력 체크 아이콘 + "내 출결" 제목
- 4칸 요약 카드(출석/지각·조퇴/결석/공결 각 건수)
- 세션별 출결 기록 목록(세로 나열, 최신순으로 추정 — 정렬 기준은 코드상 서버 응답 순서를 그대로 사용, **코드상 불명확 — 실제 화면 확인 필요**)

## 버튼/액션 전수 목록
전부 표시 전용, 클릭 가능한 요소 없음.

- **요약 카드 4개**: 출석 / 지각·조퇴(지각 두 종류+조퇴를 합산) / 결석 / 공결 각각의 누적 건수.
- **출결 기록 카드**(세션 수만큼 반복): 좌측에 주차·날짜, 가운데 세션 제목 + (공결/비고가 있으면) "사전 공결"/"사후 공결" 및 메모, 우측에 상태 배지(색상 점 + 라벨).

### 출결 상태 라벨
| 상태 | 라벨 | 색 |
|---|---|---|
| PRESENT | 출석 | 초록 |

| LATE_OVER10 | 지각(10분 이상) | 주황 |
| EARLY_LEAVE | 조퇴 | 주황 |
