# 실시간 피드백 (운영진 관리 화면)

## 진입 경로
- 사이드바 "평가" 섹션 → **"실시간 피드백"** 메뉴(하트 말풍선 아이콘)
- URL: `/live-feedback`

## 화면 구성
- 상단: 페이지 제목 "실시간 피드백" + 부제 "발표 중 기수들이 발표자에게 익명으로 남기는 상호 피드백"
- 제목 우측: **"새 보드" 버튼** (탭이 "보드 관리"일 때만 보임, "라이브 보기" 탭에서는 안 보임)
- 그 아래: **탭 전환 스위치 2개** — "보드 관리" / "라이브 보기" (알약 모양, 선택된 쪽이 흰 배경)
- 본문은 선택된 탭에 따라 완전히 달라짐

### 탭 1: 보드 관리 (기본 선택됨)
- **"실시간 피드백 사용법" 접이식 패널** (분홍 테두리 박스, 맨 위): 클릭하면 펼쳐지며 화면 스크린샷 6장 + 단계별 설명 8개 + 팁 1개가 나온다. (이 패널 자체가 사용설명서 역할을 하므로 아래 "내장 사용법" 섹션 참고)
- 보드가 없으면: 말풍선 아이콘 + "아직 생성된 피드백 보드가 없습니다." + "개인(분반) 세션을 골라 보드를 만들어 보세요." 안내문
- 보드가 있으면: **카드 그리드**(데스크탑 3열, 모바일 1열). 카드마다:
  - 보드 제목, 몇 주차 세션인지
  - 상태 배지: "진행 중"(초록) / "대기 중"(노랑, 아직 한 번도 안 열었음) / "마감"(회색, 열었다가 닫음)
  - 설정된 카테고리 미리보기 칩들(예: 칭찬, 발전 등)
  - "피드백 N개" 텍스트 + 조퇴자 포함 인원 있으면 "· 조퇴 포함 N명"
  - **버튼 5개(가로 나열)**:
    1. **"열기" / "마감하기" / "다시 열기"** (자물쇠 아이콘, 진행 중이면 "마감하기"로 문구 바뀜) — 기수원이 이 보드에 글을 쓸 수 있는지를 켜고 끈다.
    2. **라이브 보기 아이콘 버튼** (안테나 모양) — 누르면 자동으로 "라이브 보기" 탭으로 전환되면서 이 보드가 선택된 상태로 보여진다.
    3. **전체화면 아이콘 버튼** (화면 확대 모양) — 발표용 전체화면 페이지(`/live-feedback/{id}/present`)로 새로 이동한다.
    4. **수정 아이콘 버튼** (연필) — 보드 생성/수정 다이얼로그가 열림(제목·카테고리·조퇴자 포함 여부 수정 가능, 세션은 수정 불가).
    5. **삭제 아이콘 버튼** (휴지통) — 확인 대화상자가 뜬 뒤 삭제.

### 탭 2: 라이브 보기
- **보드 선택 드롭다운**: 진행 중/마감 표시와 함께 보드 목록이 나온다.
- 보드를 고르면 옆에 **"전체화면" 버튼**이 나타나 발표용 화면으로 이동할 수 있다.
- 그 아래 실제 피드백이 실시간으로 표시되는 영역(아래 "라이브 피드백 벽" 참고).
- 아무 보드도 안 골랐으면: "위에서 피드백 보드를 선택하면 실시간으로 표시됩니다." 안내문.

## 새 보드 만들기 / 수정 다이얼로그
"새 보드" 버튼이나 카드의 연필(수정) 버튼을 누르면 뜨는 창.

| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 세션 (개인/분반) | 드롭다운 | 필수 | 개인(분반) 형식 세션만 목록에 나옴. **수정할 때는 바꿀 수 없음**(생성 시에만 선택). 개인 세션이 하나도 없으면 "개인(분반) 세션이 없습니다." 경고. |
| 제목 | 텍스트(최대 100자) | 필수 | 예시: "3주차 발표 피드백" |
| 피드백 카테고리 | 카테고리 에디터(아래 설명) | 필수(각 항목에 이름 있어야 함) | 기본값: 칭찬·발전 |
| 조퇴자 포함 | 체크박스 목록 | 선택 | 그 세션에서 조퇴 처리된 사람만 후보로 뜸(결석·공결자는 항상 자동 제외). 체크한 사람만 발표자 목록에 포함됨. |

**카테고리 에디터** 상세:
- 각 카테고리 행: 이름 입력창 + 색상 드롭다운(8가지 색: 초록·노랑·하늘·보라·분홍·남색·청록·회색) + 삭제(X) 버튼(카테고리가 1개만 남으면 삭제 버튼 비활성화)
- 아래에 **프리셋 칩 버튼들**(예: 질문·총평·인상깊은 점 등 미리 정의된 카테고리) — 누르면 바로 추가됨. 이미 추가된 프리셋은 목록에서 사라짐.
- **"직접 추가" 버튼**: 이름 없는 빈 카테고리 칸을 하나 추가한다.

다이얼로그 하단: **"취소"** / **"생성"(또는 수정 시 "저장")** 버튼. 필수 항목이 안 채워지면 생성/저장 버튼이 비활성화된다.

## 보드 삭제 확인
삭제 버튼을 누르면 경고 대화상자: "'{보드제목}' 보드와 모든 피드백·반응이 삭제됩니다. 되돌릴 수 없습니다." **"취소"** / **"삭제"**(빨간 버튼) 중 선택.

## 라이브 피드백 벽 (라이브 보기 탭 안의 실제 내용)
- 상단: "총 N개 피드백" + 연결 상태 표시("실시간"/초록 와이파이 아이콘 또는 "연결 중…"/회색)
- 발표자가 없으면(분반/발표순서 미지정): "분반/발표순서를 먼저 지정하세요. (출석 탭에서 분반 배정)" 안내.
- 발표자별로 카드 묶음이 나열됨(데스크탑 3열 카드 레이아웃). 각 발표자 묶음:
  - 헤더를 누르면 접었다 펼 수 있음(화살표 아이콘 회전으로 표시). 분반이 있으면 "N분반" 배지, 발표 순서 번호(#1, #2...)도 같이 표시.
  - 그 발표자에게 온 피드백이 없으면 "아직 피드백이 없습니다."
  - **피드백 카드마다**:
    - 작성자 이름(실명), 운영진이 쓴 글이면 "운영진" 배지, 익명 글이면 "익명" 배지, 작성 시각
    - 우측 상단에 **가리기 아이콘 버튼**(눈 모양, 토글 — 가리면 카드가 흐려짐) / **삭제 아이콘 버튼**(휴지통)
    - 카테고리별 내용(칭찬/발전 등, 색깔 있는 박스)
    - **이모지 반응 바**: 이미 달린 반응은 이모지+숫자 칩으로 보이고, 점선 원(스마일+ 아이콘)을 누르면 이모지 20종 팔레트가 팝업으로 뜬다(👍❤️👏🔥🎉😮😂🥹🥺😍🤩💯🙌💪🙏✨⭐🤔👀🫶). 이미 누른 반응은 분홍색으로 강조.
    - **댓글 버튼**("댓글" + 말풍선 아이콘, 숫자 있으면 개수 표시) — 누르면 그 카드 밑에 댓글 목록이 펼쳐짐. 각 댓글에 작성자 이름(+익명이면 "익명(별명)" 배지) + 내용 + 삭제 아이콘(휴지통, 운영진은 모든 댓글 삭제 가능). 맨 아래 댓글 입력창(최대 500자) + 전송 버튼(종이비행기 아이콘).
  - 그 발표자 묶음 맨 아래, **"운영진 피드백" 버튼**(점선 테두리) — 누르면 운영진이 직접 그 발표자에게 피드백을 남기는 작성 폼이 펼쳐짐(카테고리별 textarea + "익명(기수원에겐 닉네임 — 운영진끼린 실명)" 체크박스 + "작성" 버튼). 보드가 "마감" 상태면 이 버튼 자체가 안 보임.

## 상태별 화면
- 로딩 중: 보드 목록/피드백 목록 자리에 회전하는 스피너.
- 빈 상태: 위에 각각 명시(보드 없음, 발표자 없음, 그 발표자에게 피드백 없음).
- 실시간 연결이 끊기면 "연결 중…" 표시로 바뀌고, 새로고침 없이 자동 재연결을 시도한다.

## 알아두면 좋은 것
- "마감하기"는 보드를 숨기는 게 아니라 "글쓰기만 막는" 기능이다. 마감된 보드도 기수원이 지난 피드백을 읽는 것은 계속 가능하다(작성만 안 됨).
- 삭제는 되돌릴 수 없다 — 보드를 지우면 그 안의 모든 피드백·반응·댓글이 함께 사라진다.
- 발표 시작 직전에 "열기", 끝나면 "마감하기"를 누르는 것이 권장 흐름이다(화면 내 도움말 패널의 팁).
- 분반/출석 정보는 출석 탭에서 먼저 정리해야 발표자 목록이 정확하게 잡힌다.
