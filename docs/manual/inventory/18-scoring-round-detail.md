# 심사/채점 — 라운드 상세 화면

## 진입 경로
- 심사/채점 목록 화면에서 라운드 카드 클릭
- URL: `/scoring/{roundId}`, 상단에 ← 뒤로가기(목록으로)

## 화면 구성
- 상단 `PageHeader`: 라운드 이름, 부제("{연결세션} · 대상 N팀" 또는 "독립 심사 · 대상 N팀"), 우측 버튼:
  - **[🔗 채점 링크·QR]** — `17-scoring-management.md` 참고
  - **[마감하기]**(열림 상태일 때, 테두리만) / **[링크 열기]**(마감 상태일 때, 채워진 버튼) — 실시간 채점 링크 활성/비활성 토글
- 그 아래 **탭 4개**(가로 스크롤 가능): 설정 / 제출현황 / 감점 / 결과 (기본 진입 시 "결과" 탭이 먼저 보임)
- 결과 탭은 **WebSocket으로 실시간 갱신**(다른 사람이 채점하면 화면이 자동으로 바뀜)

---

## 탭 1 — 설정

여러 개의 **접었다 펼 수 있는 패널**(아코디언, 기본 전부 펼침)로 구성. 값은 입력을 멈추면 자동 저장됨(별도 저장 버튼 없음, 화면 어딘가에 "자동 저장됨 · 방금" 같은 표시가 뜸).

### 패널: 집계 방식
- **비중 배분**: 심사위원 / 청중 점수 입력(숫자, 합계 100 고정 — 한쪽 바꾸면 반대쪽 자동 보정). 합계가 100이 아니면 빨간 배지로 경고
- **청중 채점 방식**: 두 버튼 중 선택
  - **"N위 선택"**(등수 개수는 아래에서 조정) — 청중은 순위만 투표
  - **"심사위원과 동일하게 채점"** — 청중도 기준표로 세부 채점
  - "등수 선택"을 고르면 하위 패널이 열림: **등수 가중치(%)** — 등수별로 몇 %씩 배점할지 직접 입력(예: 1위 40%, 2위 30%...), **[+ 등수 추가]**, 각 행 🗑 삭제, 합계가 100%가 아니면 **[100%로 맞추기]** 버튼으로 자동 비례 조정
- **청중 소그룹**: 그룹 이름 태그 추가/삭제(예: "기수", "운영진", "참관위원") — 그룹을 만들면 청중이 폼에서 소속을 고르게 됨(집계에는 영향 없고 결과·엑셀에서 그룹별로 나눠보기 위한 분류일 뿐). 입력창 + **[추가]** 버튼, 각 태그 옆 X로 삭제
  - **다동아리 모드** 체크박스 — 여러 동아리가 함께하는 연합 행사용. 켜면 그룹(동아리)마다 "외부 여부"·"투표 불가 팀" 지정 옵션이 추가로 나타남(본인 소속 팀에 투표 못 하게 막는 등)

### 패널: 심사 기준 (영역 → 세부항목)
- 영역을 추가하고(영역명 + 배점 + 설명), 영역 안에 세부항목을 추가(세부항목명 + 배점 + 설명)
- 세부항목이 있으면 영역 만점 = 세부항목 배점 합(자동 계산), 세부항목이 없으면 그 영역은 채점 폼에서 통째로 하나의 점수만 매김
- 각 영역/세부항목 삭제 가능(🗑)

### 패널: 심사 대상 (팀)
- 부제: "평가 폼에는 '표시 이름'이 뜹니다. 비워두면 원본 팀명이 그대로 쓰입니다."
- **[팀세션에서 가져오기]** 버튼 — 연결된 세션이 있으면 그 세션의 팀 편성을 그대로 불러옴(성공/실패 토스트)
- 팀 직접 추가: 이름 입력 + 표시 이름(선택, 평가 폼에 보일 이름)
- **"부" 나누기** 기능 있음(예선/본선처럼 여러 부로 나눠 진행하는 대회용으로 추정) — 부별로 "진행중" 표시 전환 가능, 저장 전엔 비활성

### 패널: 명단
- 부제: "제출자 이름을 이 명단과 매칭해 '누가 했는지' 체크합니다. 명단에 없어도 제출은 가능합니다."
- **[기수 멤버 가져오기]**, **[운영진 가져오기]** 버튼 — 한 번에 명단에 추가
- 검색창(이름·비고 검색)
- 개별 추가: 이름 + 소속 등(선택)

### 패널: 감점 규정
- 부제: "최종점수 = 심사 + 청중 − 감점. 규정을 만들면 아래 '감점' 탭에서 팀별로 입력합니다. (심사위원·청중에겐 안 보임)"
- 규정 종류 3가지 중 선택해서 추가:
  1. **TIME — 발표자료 지각(마감 기준 자동 판정)**: 마감 시각 설정 + 구간별 또는 분당 감점 방식, 실격 기준(이후 제출 시 실격) 설정 가능
  2. **DURATION — 발표시간 초과·미달(기준 시간)**: 기준 시간 설정, "N초 이내는 감점 없음" 여유시간, 초과/미달 각각 감점, "N분 초과 시 실격" 설정 가능
  3. **FLAG — 형식 미준수 등(체크형)**: 체크만 하면 고정 점수 감점
- 각 규정 이름은 자유 텍스트(실제 상황에 맞게 명명)

### 패널: 열람 제한
- 부제: "특정 부서 운영진이 이 라운드의 심사/채점 페이지를 볼 수 없게 합니다. 공개 링크(심사위원·청중)는 영향 없습니다."
- **열람 불가 부서** 체크박스: 회장단 / 인홍부 / 학술부 / 기획부 / 총무부 중 선택
- 부서를 하나라도 막으면 **예외 계정** 체크박스 목록이 나타나 특정 개인은 예외로 허용 가능

## 탭 2 — 제출현황
- 명단 매칭 여부, 제출시각, 입력한 이름(자유 참가면 명단과 무관하게 이름만 받음) 등을 확인하는 화면
- **명단 체크리스트**: 명단에 있는 사람 기준 제출/미제출 표시(전원 제출 완료 시 안내)
- **명단 전체에서 찾기** 기능(제출자를 명단과 수동 매칭하는 용도로 추정)
- 본인 소속팀 채점 여부 등 세부 정보(실제 화면 확인 필요 — 코드가 커서 세부 라벨까지는 다 못 훑음)
- **순위·피드백** 관련 열람도 이 탭에서 가능(다동아리/RANK 모드일 때)

## 탭 3 — 감점
- 부제 격 안내(설정 탭에서 만든 규정이 팀마다 나열됨): "설정 탭에서 만든 규정이 팀마다 나옵니다. 발표자료 지각은 실제 제출시각을, 발표시간 초과·미달은 실제 발표시간을, 형식 미준수는 체크만 하면 서버가 감점·실격을 자동 계산합니다."
- 팀별로 각 감점 규정에 대해 실제 값(제출시각/발표시간/체크)을 입력 → 자동 저장 → 감점 자동 계산되어 결과 탭에 반영
- 감점 내용은 심사위원·청중에게는 노출되지 않음

## 탭 4 — 결과 (실시간)
- **팀별 총점** — 최종 순위표(심사 + 청중 − 감점)
- **영역별 강약점** — 기준마다 배점이 달라 만점 대비 %로 환산해 팀 간 비교(영역·기준 3개 이상이면 레이더 차트로 표시)
- **심사위원별 부여 점수** — 심사위원마다 어떻게 채점했는지 상세
- **청중상 순위** — 등수별 득표 수(몰표인지 갈렸는지)
- **청중 그룹**별로 나눠보기(그룹 설정한 경우)
- **제출자별 상세** — 개인 제출 기록 열람
- **서술형 피드백** — 청중 피드백(RANK 모드에서 별도 폼으로 받은 것)
- **감점전 / 최종** 전환해서 감점 반영 전후 비교 가능
- 일부 데이터가 아직 없으면 "부분 집계 중" 등 안내 표시
- (목록 화면 안내에 언급된) **엑셀 내보내기** 기능 존재 — 정확한 버튼 위치는 화면 확인 필요

## 알아두면 좋은 것
- 설정 탭 전체가 자동 저장 방식 — "저장" 버튼을 누를 필요 없이 입력을 멈추면 반영됨
- 링크를 "마감"해도 이미 설정된 심사 기준/감점 데이터는 그대로 남음(다시 열면 이어서 받을 수 있음)
- 결과 탭은 실시간이라 심사 도중에도 계속 열어두고 지켜볼 수 있음
