# 기수 포털 홈

## 진입 경로
- 하단 탭 "홈" (항상 첫 화면, 로그인 직후 기본 도착 화면)
- URL: `/member`

## 화면 구성
위에서 아래 순서로:
1. (조건부) 실시간 피드백 진행 중 배너
2. "한눈에 보기" 카드(점수 요약 3칸)
3. "메뉴" 섹션 — 5개 메뉴 카드(2열 그리드)

## 버튼/액션 전수 목록

### 실시간 피드백 진행 중 배너 (현재 열려 있는 피드백 보드가 있을 때만 표시)
- 왼쪽 아이콘(하트 말풍선) + 빨간 점 깜빡임 애니메이션 + "실시간 피드백 진행 중" 굵은 글씨
- 아래 작은 글씨로 "{보드 제목} · 발표자에게 익명으로 남겨보세요"
- 카드 전체가 버튼 — 클릭 시 해당 피드백 보드 화면(`/member/feedback/{보드ID}`)으로 바로 이동.
- 열린 보드가 없으면 이 배너 자체가 안 보임(공간도 안 차지).

### 한눈에 보기 카드 (클릭 불가, 정보 표시 전용)
3칸 표시:
- **총점**: `net_score` 숫자
- **상점/벌점**: 초록색 상점 숫자 / 빨간색 벌점 숫자 (슬래시로 구분)
- **디파짓**: 만원 단위로 소수 첫째자리까지(예: "2.0만")
- 데이터 로딩 중엔 각 칸에 "—" 표시.

### 메뉴 카드 (5개, 2열 그리드 — 마지막 카드는 혼자 남아 한 줄 차지)
| 아이콘 | 제목 | 설명 | 이동 경로 |
|---|---|---|---|
| 확성기 | 공지사항 | 운영진 공지 확인 | `/member/announcements` |
| 막대그래프 | 성장 리포트 | 초기·후기 평가 | `/member/reports` |
| 하트 말풍선 | 실시간 피드백 | 발표 피드백 보드 | `/member/feedback` |
| 지갑 | 내 점수·장부 | 상·벌점·디파짓 | `/member/ledger` |
| 달력 체크 | 내 출결 | 주차별 출석 현황 | `/member/attendance` |

- 각 카드 전체가 버튼. 탭 시 살짝 눌리는 애니메이션 효과.

## 폼/입력 필드
없음(입력 폼 없는 대시보드형 화면).

## 상태별 화면
- **로딩 중**: 한눈에 보기 카드의 숫자들이 "—"로 표시(카드 자체는 항상 보임).
- **빈 상태**: 별도 없음(요약 데이터가 0이어도 0으로 표시됨).
- **에러**: 이 화면 자체에서 별도 에러 UI 없음(코드상 불명확 — 실제 화면 확인 필요, 아마 토스트나 빈 값으로 처리될 것으로 추정).

## 알아두면 좋은 것
- **"내 출결" 메뉴는 하단 탭바에는 없고 이 홈 화면의 메뉴 카드에서만 들어갈 수 있다** — 놓치기 쉬운 진입 경로이므로 사용설명서에서 강조 필요.
- 실시간 피드백 배너는 운영진이 보드를 "공개" 상태로 켜둔 동안에만 나타나는 실시간성 배너라, 평소엔 안 보이다가 발표 세션 중에만 뜬다는 점을 사용자에게 설명해야 헷갈리지 않음.
