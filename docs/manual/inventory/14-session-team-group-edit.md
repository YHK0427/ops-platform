# 팀 편집 / 분반 편집 (세션 상세 하위 화면)

두 화면 모두 세션 상세의 "출석" 탭에 있는 버튼에서 진입하며, 조작 UI는 동일한 드래그앤드롭 팀빌딩 에디터를 재사용한다(자세한 조작법은 세션 생성 마법사 문서의 "팀 빌딩"/"분반 나누기" 단계와 완전히 동일 — 멤버 카드 탭 선택, 우측 손잡이로 드래그, 이름 검색, "N명 이동" 팝오버, "자동 생성/분배" 버튼 등).

---

## 팀 편집

### 진입 경로
- 세션 상세 "출석" 탭에서, 팀 세션이고 상태가 `PREP`일 때 표시되는 **"팀 수정" 버튼** 클릭
- URL: `/sessions/{id}/team-edit`

### 화면 구성
- 제목 "팀 수정" + 안내문 "멤버를 클릭해 여러 명을 선택한 후 함께 드래그하여 팀 간 이동할 수 있습니다"
- 팀 빌딩 에디터(팀 추가/삭제/이름변경 전부 가능, 미배정 칼럼 있음) — 세션 생성 시 배정했던 팀 구성이 초기값으로 불러와짐(팀에 없는 활성 멤버는 자동으로 "미배정"에 들어감)

### 버튼
- **"팀 저장"** (우측 하단): 현재 팀 구성을 세션에 저장. 저장 중엔 "저장 중" 표시. 성공하면 "팀 구성이 저장되었습니다" 토스트 + "출석" 탭으로 자동 복귀
- **"← 돌아가기"** (좌측 하단): 저장하지 않고 "출석" 탭으로 복귀(변경사항 버려짐)

---

## 분반 편집

### 진입 경로
- 세션 상세 "출석" 탭에서, 개인 세션+분반 옵션이 켜져 있고 상태가 `SETUP` 또는 `PREP`일 때 표시되는 **"분반 수정" 버튼** 클릭
- URL: `/sessions/{id}/group-edit`

### 화면 구성
- 제목 "분반 수정" + 안내문 "멤버를 드래그하여 분반 간 이동할 수 있습니다. 운영진 배치는 아래에서 설정하세요"
- **운영진 배치 박스** (담당 운영진이 있을 때만 표시): 각 운영진 이름 옆에 **"1"/"2" 버튼** — 클릭해서 그 운영진을 1분반 또는 2분반 담당으로 지정(다시 누르면 해제, 파란색=1분반/초록색=2분반)
- 분반 빌딩 에디터: 칼럼이 "1분반"/"2분반"으로 고정(추가/삭제/이름변경 불가), "자동 분배" 버튼으로 랜덤 절반씩 배정 가능. 현재 출석표에 저장된 분반 배정이 초기값

### 버튼
- **"분반 저장"**: 현재 분반 구성 + 운영진 배치를 함께 저장. 성공하면 "분반이 저장되었습니다" 토스트 + "출석" 탭으로 복귀
- **"← 돌아가기"**: 저장하지 않고 복귀

## 알아두면 좋은 것
- 두 화면 모두 "돌아가기"를 누르면 그 사이 변경한 내용은 전부 사라짐(저장 안 된 상태)
- 팀/분반 편집은 세션이 특정 상태(PREP 또는 SETUP/PREP)일 때만 진입 가능 — 세션이 더 진행되면(OPS 이상) 버튼 자체가 안 보여서 수정할 수 없음
