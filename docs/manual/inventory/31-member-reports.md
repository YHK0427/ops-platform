# 발표 성장 리포트 (목록)

## 진입 경로
- 하단 탭 "리포트"
- 홈 화면의 "성장 리포트" 메뉴 카드
- URL: `/member/reports`

이 화면은 평가 라운드 목록이며, 실제 평가 작성/결과 열람은 여기서 각 라운드 카드의 버튼을 눌러 별도 화면(`/member/eval/...`)으로 들어가야 한다. → `35-member-eval-flow.md` 참조.

## 화면 구성
- 상단: 클립보드 아이콘 + "발표 성장 리포트" 제목
- 본문: 평가 라운드 카드 목록(세로 나열, 순서대로 살짝 나타나는 애니메이션)

## 버튼/액션 전수 목록

각 라운드 카드에는 아래 정보와 버튼이 표시됨(라운드 상태에 따라 버튼 유무가 달라짐):
- 라운드 제목 + (제출을 이미 했으면) 초록색 "제출 완료" 배지
- 세션 제목(있으면)
- **"평가하기" 버튼**(빨간 배경) — 아직 제출 안 했고 평가가 열려있는 라운드에서만 표시. 클릭 시 자기평가 작성 화면(`/member/eval/{라운드ID}`)으로 이동.
- **"수정하기" 버튼**(회색 배경, 위와 같은 위치) — 이미 제출했지만 평가가 아직 열려있으면 "평가하기" 대신 이 버튼이 뜸. 클릭 시 같은 작성 화면으로 이동(기존 응답 수정 가능하다는 뜻으로 추정).
- **"결과 보기" 버튼**(하늘색) — 운영진이 해당 라운드 결과를 공개했을 때만 표시. 클릭 시 결과 화면(`/member/eval/{라운드ID}/result`)으로 이동.
- 평가가 닫혀 있고(`is_open` false) 결과도 아직 공개 안 됐으면(`results_open` false) 이 카드엔 버튼이 하나도 안 뜨고 정보만 표시됨.

## 폼/입력 필드
없음(목록 화면).

## 상태별 화면
- **로딩 중**: 가운데 작은 스피너.
- **빈 상태**: "현재 진행 중인 평가가 없습니다" + 받은편지함 아이콘.

## 알아두면 좋은 것
- "평가하기"와 "결과 보기" 버튼이 동시에 뜨는 경우도 있다(자기평가는 아직 열려있는데 다른 라운드 결과는 공개된 경우 등, 라운드별로 독립적으로 계산됨).
- 평가를 이미 제출한 뒤에도 라운드가 열려있는 동안엔 "수정하기"로 계속 다시 들어가 고칠 수 있다.
