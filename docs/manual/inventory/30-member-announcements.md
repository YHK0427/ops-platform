# 공지사항 (목록 + 상세)

## 진입 경로
- 하단 탭 "공지" → 목록 화면(`/member/announcements`)
- 목록에서 카드 클릭 → 상세 화면(`/member/announcements/{공지ID}`)
- 홈 화면의 "공지사항" 메뉴 카드에서도 목록으로 진입 가능
- 웹푸시 알림을 눌러 앱을 열면 해당 공지 상세로 바로 이동하는 경로도 있음(다른 세션에서 확인된 `/go/announcement/:id` 랜딩 — 이 fork 범위 밖 파일이라 **코드상 불명확, 실제 확인 필요**)

## 화면 구성 — 목록
- 상단: 확성기 아이콘 + "공지사항" 제목(좌측), "알림 받기" 버튼(우측)
- 본문: 공지 카드 목록(세로 나열), 각 카드에 제목/미리보기/작성일시/작성자/해시태그/반응 이모지, 오른쪽에 썸네일 이미지 또는 화살표 아이콘

## 화면 구성 — 상세
- 상단: "← 공지 목록" 뒤로가기 버튼
- 본문 카드: "공지" 라벨, 제목, 작성일시·작성자, 해시태그, 구분선, 본문(리치 텍스트 — 이미지/링크카드/표/유튜브 임베드 등 포함 가능), 구분선, "이 공지에 반응 남기기" + 이모지 반응, 구분선, 댓글 영역

## 버튼/액션 전수 목록

### 목록 화면
- **"알림 받기" / "알림 끄기" 버튼**(상단 우측, 종 아이콘)
  - 처음엔 "알림 받기"(색깔 배경). 클릭 시 브라우저 푸시 구독 요청 → 성공하면 "알림 켰습니다 🔔" 토스트 + 버튼이 회색 "알림 끄기"로 바뀜.
  - 다시 클릭하면 구독 해제 + "알림을 껐습니다" 토스트.
  - 아이폰인데 홈 화면에 앱을 안 깔았으면: 클릭 시 바로 구독 시도 대신 **설치 안내 팝업**이 뜬다("아이폰 알림 설정" — 사파리 공유 버튼 → 홈 화면에 추가 → 앱에서 다시 알림 받기, 3단계 안내). 팝업엔 "알겠어요" 버튼으로 닫기.
  - 브라우저가 알림 자체를 지원 안 하면 버튼 대신 "이 브라우저는 푸시 알림을 지원하지 않아요" 문구만 표시.
  - 브라우저 알림 권한을 이미 거부했으면 버튼이 비활성화되고 아래 "브라우저에서 알림이 차단돼 있어요..." 안내 문구 표시.
- **공지 카드**(목록에 있는 만큼 반복)
  - 카드 전체 클릭 시: 해당 공지 상세 화면으로 이동.
  - 카드 안에 표시되는 이모지 반응 칩은 이 목록 화면에서는 **읽기 전용**(숫자만 보임, 눌러도 반응 안 됨 — 반응은 상세 화면에서만 가능).

### 상세 화면
- **"← 공지 목록" 버튼**(최상단): 클릭 시 목록 화면으로 돌아감.
- **이모지 반응 영역** ("이 공지에 반응 남기기" 문구 아래)
  - 이미 반응이 달린 이모지는 칩(동그란 배지)으로 표시, 숫자와 함께. 본인이 누른 반응은 rose색으로 강조.
  - 칩을 다시 누르면 반응 취소(토글).
  - **"+😊" 점선 원 버튼**: 클릭 시 이모지 선택 팝업이 뜸. 사용 가능 이모지 7종: 👍 ❤️ 🔥 👏 🎉 🥹 👀. 팝업에서 하나 누르면 그 반응이 추가되고 팝업 자동 닫힘.
- **댓글 영역**
  - 댓글 목록: 작성자 이름 첫 글자 원형 아바타(운영진이 쓴 댓글은 진한 rose 배경 + "운영진" 배지), 이름, 상대 시간("방금"/"n분 전"/"n시간 전"/"n일 전"), 댓글 내용.
  - 댓글이 하나도 없으면 "첫 댓글을 남겨보세요" 문구.
  - **본인이 쓴 댓글에만** 우측에 휴지통 아이콘 버튼 — 클릭 시 브라우저 confirm 팝업("댓글을 삭제할까요?") → 확인하면 즉시 삭제.
  - 하단 입력창 + **전송 버튼**(종이비행기 아이콘)
    - 입력 후 Enter 키 또는 전송 버튼 클릭으로 등록.
    - 빈 텍스트거나 전송 처리 중이면 전송 버튼 비활성화.
    - 최대 1000자.

## 폼/입력 필드
| 필드 | 위치 | 타입 | 필수 | 비고 |
|---|---|---|---|---|
| 댓글 내용 | 상세 화면 하단 | 텍스트(한 줄 입력창) | 예(빈 값이면 전송 안 됨) | 최대 1000자 |

## 상태별 화면
- **로딩 중**: 목록/상세 모두 "불러오는 중…" 문구만 가운데 표시.
- **빈 상태**: 목록에 공지가 하나도 없으면 "아직 공지가 없어요". 댓글이 없으면 "첫 댓글을 남겨보세요".
- **에러(상세)**: 존재하지 않는 공지 ID로 접근 시 "공지를 찾을 수 없어요".

## 알아두면 좋은 것
- 목록 카드의 반응 이모지는 보기만 가능하고, 실제로 반응을 남기거나 취소하려면 반드시 공지를 열어 상세 화면으로 들어가야 한다 — 사용자가 목록에서 반응 누르려다 안 눌려서 헷갈릴 수 있음.
- 댓글 삭제는 브라우저 기본 confirm 팝업으로 한 번 더 확인하지만, 확인 후엔 되돌릴 수 없음(휴지통이나 복구 기능 없음).
- 알림 받기는 기기/브라우저별로 따로 설정해야 함(한 기기에서 켰다고 다른 기기에서 자동으로 켜지지 않음). 아이폰 사파리는 홈 화면 설치가 필수 전제조건.
