# 팀 빌딩 도우미 — 보드 편집 화면

## 진입 경로
- 팀 빌딩 목록 화면에서 보드 카드 클릭, 또는 새 보드 생성 직후 자동 이동
- URL: `/team-building/{boardId}`, 상단 ← 버튼으로 목록 복귀

## 화면 구성
- 상단 바: ← 뒤로가기, 보드 이름, 부제("선택한 과거 팀세션과 안 겹치게 · 운영진은 과거 팀에 기록하면 겹침 계산"), 우측에 실시간 **겹침 N** 카운터 배지(0이면 초록, 아니면 빨강)
- **사용법 패널**(접었다 펼치기, 기본 펼침) — 앱에 내장된 안내 6개:
  1. 과거 세션 선택 — 겹침 기준으로 삼을 과거 팀세션을 켬. 그 세션에서 같은 팀이었던 사람끼리 안 만나게 회피
  2. 과거 팀에 운영진 기록 — 기수 기록만 있는 과거 팀에 운영진을 끌어다 넣으면 운영진 겹침도 계산됨
  3. 운영진 참여/충돌 고려 — 이번 팀빌딩에 넣을 운영진 선택 + 기수↔운영진, 운영진↔운영진 겹침 회피 여부(기수↔기수는 항상 회피)
  4. 충돌 최소화 랜덤 — 현재 설정 기준 겹침 최소 조합 자동 계산
  5. 드래그(PC·모바일) — 칩을 끌어 팀 이동(모바일은 길게 눌러서 드래그). 자동 저장됨
  6. 보드 저장 — 여러 보드를 목적별로 따로 관리 가능

### 겹침 기준 과거 팀세션 선택
- 완료된 과거 팀 세션들이 카드(체크박스) 형태로 나열됨(주차 + 제목), 클릭해서 켜고 끄기. 선택한 세션 수가 배지로 표시됨

### 과거 팀에 운영진 기록 (팀세션 선택 시에만 등장, 접이식, 노란색 강조)
- 선택한 과거 세션마다: "미배치 운영진" 목록(드래그 가능한 알약 모양 칩) + 그 세션의 팀 칸들(드롭 영역)
- 운영진 칩을 팀 칸으로 드래그하면 "이 운영진 = 이 팀이었다" 기록됨(원래 팀 기록엔 기수만 있어서 이걸로 보완). 배치된 운영진은 X 버튼으로 배치 해제 가능
- 전부 기록 완료 시 "모두 배치됨 ✓" 표시

### 운영진 참여 설정
- 이번 팀빌딩에 참여시킬 운영진 토글 칩 목록(제외하면 점선+취소선 표시), "참여 N · 제외 N" 카운트
- **충돌 고려** 토글: "기수↔기수"(항상 켜짐, 끌 수 없음) / "기수↔운영진" / "운영진↔운영진" — 각각 켜고 끄기 가능

### 툴바
- **[🎲 충돌 최소화 랜덤]** — 최대 3000회 무작위 시도 중 겹침 점수가 가장 낮은 배치를 자동 적용(기수-기수 겹침에 가장 큰 가중치, 그 다음 기수-운영진, 그 다음 운영진-운영진). 성공 시 "겹침 0으로 배정!" 또는 "최소 겹침으로 배정 (점수 N)" 토스트
- **[🔄 전부 풀로]** — 모든 배정을 취소하고 미배정 상태로 되돌림
- **[📋 결과 복사]** — 팀별 명단을 텍스트로 클립보드에 복사("팀 1: 홍길동, 김철수(운영), ..." 형식)
- **팀 수** 숫자 입력(2~12)

### 미배정 풀 + 팀 칸들
- "미배정 (N)" 영역 — 아직 어느 팀에도 안 들어간 사람들(점선 테두리 드롭 영역)
- 팀 칸(팀 수만큼, 그리드): 각 칸 상단에 "팀 N" + "기수 N·운영 N" 인원 요약, 그 아래 배정된 사람 칩들
- **사람 칩을 드래그해서** 미배정 ↔ 팀, 팀 ↔ 팀 사이로 자유롭게 이동(자동 저장, 별도 저장 버튼 없음 — 변경 후 약 0.7초 뒤 서버에 저장)
- 칩에 겹침이 있으면 숫자 배지 표시(빨강=기수 간 겹침 포함, 주황=그 외), 마우스를 올리면 하이라이트되고 같은 팀 안에서 겹치는 상대가 하늘색으로 강조됨

### 마우스 오버 상세 패널
- 사람 칩에 마우스를 올리면 그 사람이 지금 속한 팀 안에서 누구와 겹치는지, 어느 세션에서 겹쳤는지 자세히 표시. 아무것도 안 올렸으면 "멤버에 마우스를 올리면 누구와 어느 세션에서 겹쳤는지 보여줘요" 안내

### 하단 겹침 통계
- 유형별 카운트: 기수↔기수(빨강) / 기수↔운영(주황) / 운영↔운영(회색)
- 겹침 목록 — 겹치는 두 사람 이름 + 유형 배지 + 소속 팀 번호. 겹침이 0건이면 "✓ 겹침 없음"

## 알아두면 좋은 것
- 모든 조작은 **자동 저장**(드래그, 세션 선택, 운영진 설정 등) — 별도 저장 버튼 없음
- "충돌 최소화 랜덤"은 완벽하게 0건을 보장하지 않음(인원 구성상 불가능할 수도 있음) — 점수가 가장 낮은 조합을 고를 뿐
- 세션/팀/도우미(SessionWizard의 팀 배정, TeamEditPage 등)와는 **별개의 독립 기능** — 이 보드에서 짠 팀은 자동으로 실제 세션에 반영되지 않음(결과 복사해서 수동으로 활용하는 방식으로 추정, 실제 연동 여부는 화면 확인 필요)
