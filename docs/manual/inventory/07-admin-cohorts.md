# 기수 공간 관리

## 진입 경로
- 사이드바 "관리" 구역의 "**기수 공간 관리**" (레이어 아이콘) — **슈퍼관리자(전체 관리자)만** 보임. 일반 admin(특정 기수 소속)에게는 사이드바에 이 메뉴 자체가 안 보임.
- URL: `/admin/cohorts`
- 만약 슈퍼관리자가 아닌 사람이 URL로 직접 접근하면 "기수 공간 관리는 전체 관리자(슈퍼관리자)만 접근할 수 있습니다." 안내 문구만 표시됨(사이드바 메뉴는 숨겨져 있지만 화면 자체는 접근 시도 시 이렇게 방어됨).

## 화면 구성
- 상단: "기수 공간 관리" 제목 + "기수별 독립 공간 · 현재 보는 기수: OOO" 부제 + 우측 **"새 기수 만들기"** 버튼
- 본문: 기수 카드 목록(2열 그리드, 넓은 화면 기준)

## 버튼/액션 전수 목록

### 상단
- **"새 기수 만들기"** 버튼(+아이콘) — "새 기수 공간 만들기" 다이얼로그 열림(아래 참조)

### 각 기수 카드
- 카드 안 표시: 기수 이름 + 배지들("활성 기수" 초록 — 이 기수가 시스템의 기본/현재 기수로 지정됨, "보는 중" 파랑 — 지금 관리자가 보고 있는 기수, "보관됨" 회색 — 로그인 차단된 상태) + "N기" + 슬로건 입력창(아래 참조)
- **"보기"** 버튼(눈 아이콘) — 클릭하면 그 기수 공간으로 전환(다른 기수의 세션·멤버·장부 등을 보게 됨). "OOO 공간으로 전환했습니다" 토스트 후 전체 데이터 재조회. 현재 보고 있는 기수면 버튼이 진하게 강조 표시됨
- **"활성으로" / "활성 해제"** 버튼(체크 아이콘, 보관되지 않은 기수만 표시) — 이 기수를 시스템의 "현재 기수"(기본 활성 기수)로 지정/해제. 이미 활성이면 초록색으로 강조되고 라벨이 "활성 해제"로 바뀜
- **"운영진 추가"** 버튼(사람+아이콘) — "OOO 운영진 추가" 다이얼로그(이 기수 소속 운영진 계정 생성, 아래 참조)
- **보관 상태에 따라**:
  - 보관 안 된 기수: **보관 아이콘 버튼**(Archive, 라벨 없이 아이콘만, 툴팁 "보관(비활성·로그인 차단)") — 클릭 시 해당 기수를 보관 처리(그 기수 소속 계정들 로그인 차단)
  - 보관된 기수: **"보관 해제"** 버튼(툴팁 "보관 해제(로그인 재허용)") — 클릭 시 로그인 다시 허용

### 슬로건 인라인 편집
- 카드 안에 텍스트 입력창("발표 성장 리포트 슬로건 (비우면 기본 문구)") — 값을 바꾸면 옆에 **저장 아이콘 버튼**이 나타남(값이 원래와 달라졌을 때만 표시) → 클릭하면 즉시 저장, "슬로건을 저장했습니다" 토스트. 이 슬로건은 해당 기수의 발표 성장 리포트 표지에 쓰이는 문구.

## 폼/입력 필드

### "새 기수 공간 만들기" 다이얼로그
- **기수 번호** 숫자(필수, 예: 34)
- **이름** 텍스트(선택, 비우면 "N기"로 자동 지정)
- 안내: "빈 공간이 생성됩니다. 멤버·세션은 새로 등록하세요."
- 제출: **"만들기"**(번호 없으면 비활성)

### "OOO 운영진 추가" 다이얼로그
- **아이디**, **비밀번호**, **표시 이름** (전부 필수)
- **권한** 드롭다운: 운영진 / 열람자 — **admin 역할은 이 다이얼로그로 만들 수 없음**(안내문에 명시: "admin 역할은 불가")
- **부서** 드롭다운: 회장단/인홍부/학술부/기획부/총무부(기본값 회장단)
- 제출: **"추가"**(전부 채워야 활성화)

## 상태별 화면
- **로딩 중**: 중앙 스피너
- **권한 없음**(슈퍼관리자 아님): 안내 문구 텍스트만 표시(위 참조), 다른 UI 없음
- **에러**: 기수 생성/운영진 추가 실패 시 토스트로 서버 에러 메시지 표시("생성 실패", "추가 실패" 또는 서버가 준 구체적 사유), 슬로건 저장 실패는 "저장 실패" 토스트

## 알아두면 좋은 것
- **"보기"(현재 보는 기수 전환)와 "활성으로"(시스템 기본 기수 지정)는 서로 다른 개념**이다 — "보기"는 지금 이 관리자 브라우저 세션에서만 어느 기수 데이터를 볼지 정하는 것이고, "활성으로"는 전체 시스템 차원에서 "현재 진행 중인 기수"를 표시하는 것. 헷갈리지 않아야 함.
- "보관"은 삭제가 아니라 로그인 차단이다 — 데이터는 그대로 남고 나중에 "보관 해제"로 되돌릴 수 있음.
- 이 화면에서 만든 운영진 계정은 admin 권한을 줄 수 없다 — 슈퍼관리자(admin, cohort 없음)는 이 화면이 아닌 다른 경로로만 생성 가능(코드상 이 경로는 확인 안 됨 — 실제로는 DB 시드나 별도 스크립트로 최초 생성되는 것으로 보임, 실제 확인 필요).
- 새 기수를 만들면 완전히 빈 공간이 생긴다 — 멤버/세션 등은 하나도 없이 시작하므로, 이후 "운영진 추가"와 "멤버" 화면에서의 멤버 추가, "기수 관리" 탭의 기수원 계정 생성 등을 순서대로 진행해야 한다.
