# 대시보드

## 진입 경로
- 사이드바 최상단 "**대시보드**" (LayoutDashboard 아이콘) — 모든 운영진(admin/manager/viewer)에게 보임. `scoring_only` 역할은 이 메뉴 자체가 사이드바에 없음(심사/채점만 보임).
- 로그인 직후 자동으로 이 화면으로 이동 (운영진 로그인 시 기본 진입점).
- 좌측 상단 로고("UnivPT Ops") 클릭해도 이 화면으로 이동.
- URL: `/dashboard`

## 화면 구성
상단에 "대시보드" 제목 + "전체 운영 현황 및 리스크 모니터링" 부제(PageHeader, 우측 액션 버튼 없음).

본문은 위에서 아래로 3개 섹션이 세로로 쌓인 구조(카드형):
1. **네이버 세션 상태** 카드
2. **현재 세션** 카드
3. **위험 인물 한눈에** — 5개 카드가 그리드로(데스크탑 5열, 모바일 2열)

로딩 중에는 화면 전체에 스피너(회전하는 원) 하나만 표시됨.

## 버튼/액션 전수 목록

### ① 네이버 세션 상태 카드
- 좌측에 자물쇠 아이콘(초록=정상/빨강=만료) + "네이버 세션 상태" 제목 + 상태 텍스트
  - 유효할 때: 초록 점 + "유효 · YYYY.MM.DD까지 (약 N일 남음)"
  - 만료/무효일 때: 빨강 점 + "만료됨 — 재로그인이 필요합니다"
  - 만료일 정보가 없는 경우: "유효 (만료일 정보 없음)"
- 우측 버튼 2개(기본 상태, 로그인 진행 중이면 둘 다 비활성화):
  - **"네이버 로그인"** (빨간 배경 버튼) — 클릭 시 로그인 폼(아이디/비밀번호 입력창)이 카드 아래에 펼쳐짐
  - **"수동 가져오기"** (텍스트 링크) — 클릭 시 쿠키 수동 등록 안내가 카드 아래에 펼쳐짐
  - 로그인 작업이 진행 중이면 "네이버 로그인 진행 중..." 파란 점 애니메이션이 버튼 위에 표시됨
- **로그인 폼 펼쳐진 상태**:
  - "네이버 ID" 입력창, "비밀번호" 입력창(둘 다 텍스트)
  - **"취소"** 버튼(폼 접기)
  - **"자동 로그인"** 버튼(초록) — 아이디/비밀번호 둘 다 입력해야 활성화. 클릭 시 서버에 로그인 요청 전송하고 작업 완료를 기다림 → 성공 시 "네이버 로그인 성공!" 토스트, 실패(캡차 등) 시 "네이버 로그인 실패: (사유) — 수동 가져오기를 이용하세요" 토스트
  - 폼 하단에 "로그인 정보는 서버에서 안전하게 처리되며 저장되지 않습니다" 안내 문구
- **수동 가져오기 폼 펼쳐진 상태**:
  - 노란 경고 박스: "네이버 정책상 자동 로그인은 캡차로 자주 실패합니다..." 안내
  - 1·2·3단계 텍스트 안내(시크릿 창에서 naver.com 로그인 → 개발자도구 Application→Cookies 열기 → NID_AUT/NID_SES 값 복사)
  - 안내 스크린샷 이미지 1장
  - "NID_AUT 값 붙여넣기", "NID_SES 값 붙여넣기" 입력창 2개
  - **"쿠키로 등록"** 버튼(초록) — 둘 다 입력해야 활성화, 클릭 중엔 "등록 중..."으로 바뀜
  - 하단 `<details>` 접이식 섹션 "고급 · storageState JSON 직접 붙여넣기" — 펼치면 JSON 붙여넣는 큰 텍스트영역 + **"JSON 가져오기"** 버튼(로딩 중엔 "가져오는 중...")

### ② 현재 세션 카드
- **세션이 있을 때**: 우상단에 상태 배지(SETUP/PREP/OPS/POST/SETTLEMENT/FINALIZED), "N주차" 배지, (오늘 세션이고 22시 이후거나 지난 세션이면) "입장 마감" 자물쇠 표시, 세션 제목(큰 글씨), "개인/팀 세션" 텍스트
  - 하단에 통계 4칸: 출석률(%), PPT 이메일 제출(N/총원), 과제 제출(N/총원), 그리고 **"세션 관리"** 버튼 — 클릭 시 세션 상태에 맞는 탭으로 자동 이동(SETUP/PREP→준비 탭, OPS→진행 탭, POST/FINALIZED 아니면→검사 탭, SETTLEMENT/FINALIZED→정산 탭)
- **세션이 없을 때**: "예정된 세션이 없습니다" 문구 + **"세션 생성하기"** 버튼(클릭 시 `/sessions/new`로 이동)

### ③ 위험 인물 한눈에
- 부제: "(이름을 누르면 멤버 상세로 이동)"
- 위험 신호가 하나도 없으면 초록 박스로 "현재 위험 신호가 감지된 멤버가 없습니다"만 표시
- 위험 신호가 있으면 카드 5개(위험 없는 항목은 회색으로, 있는 항목은 빨강/주황으로 강조):
  1. **퇴출 위험** — 순점수 -13점 이하
  2. **퇴출 경고** — 순점수 -7~-12점
  3. **벌금 임박** — 누적벌점 5천원 부과까지 3점 이내
  4. **디파짓 부족** — 잔액 10,000원 미만
  5. **벌금 미납** — 마일스톤 누적벌금 미납
  - 각 카드: 인원수(N명) + 힌트 문구 + 해당 멤버 이름 태그들(칩 형태) — **이름 칩을 클릭하면 해당 멤버의 상세 페이지(`/members/{id}`)로 이동**

## 폼/입력 필드
(위 "네이버 세션 상태" 카드 안의 두 폼 참조. 그 외 다이얼로그/시트 없음.)

## 상태별 화면
- **로딩 중**: 화면 중앙에 회전 스피너만 표시(세션·멤버·네이버 상태 데이터를 모두 가져올 때까지)
- **세션 없음**: "예정된 세션이 없습니다" + 생성 버튼 (위 참조)
- **위험 인물 없음**: 초록색 안내 문구 (위 참조)
- **에러 처리**: 코드상 명시적 에러 UI는 없음 — 네이버 로그인/가져오기 실패 시 토스트 알림으로만 안내됨. 데이터 조회 자체가 실패하는 경우의 화면은 코드상 불명확 — 실제 화면 확인 필요.

## 알아두면 좋은 것
- 네이버 로그인은 캡차 때문에 자주 실패하니, 실패하면 "수동 가져오기"로 쿠키(NID_AUT, NID_SES)를 직접 등록하는 방법을 안내받게 된다.
- "수동 가져오기"의 안내대로 시크릿(인코그니토) 창에서 로그인하면 평소 쓰는 브라우저 로그인 상태에 영향 없음.
- 위험 인물 카드는 전부 클릭 가능한 이름 칩이 있어 바로 해당 멤버 상세로 넘어갈 수 있음 — 별도 검색 없이 빠르게 조치 가능.
- 파괴적 액션(삭제 등)은 이 화면에 없음.
