# 심사/채점 — 목록 화면

## 진입 경로
- 사이드바 "평가" 그룹 → **심사/채점** 메뉴
- URL: `/scoring`

## 화면 구성
- 상단 `PageHeader`: 제목 "심사/채점", 부제 "공개 링크를 뿌려 심사위원·청중 점수를 모으고 실시간으로 집계합니다", 우측 **[+ 새 심사]** 버튼
- 화면 상단에 **사용법 안내 패널**(`ScreenGuide`, 접었다 펼치는 형태로 추정 — 기본 펼침) — 스크린샷 6장 + 6단계 설명이 이미 앱 안에 내장되어 있음(아래 "코드에 이미 있는 사용법" 참고)
- 라운드가 없으면: 안내 아이콘 + "아직 심사 라운드가 없어요. **새 심사**로 만들어보세요." + 부연 설명
- 라운드가 있으면: 카드 그리드(데스크탑 2열)

### 라운드 카드
- 아이콘(망치), 이름, 상태 배지(**열림**=초록 / **마감**=회색)
- 부제: "{연결 세션명} · " (있으면) + "대상 N팀 · 제출 N명"
- 우측 아이콘 버튼: 🔗(채점 링크·QR 열기), 🗑(삭제 — hover 시에만 나타남, 빨강)
- 카드 전체 클릭 → 해당 라운드 상세 화면(`/scoring/{id}`)으로 이동
- 삭제 버튼은 브라우저 기본 `confirm()` 대화상자로 "'{이름}' 심사를 삭제할까요? 제출된 점수도 함께 사라집니다." 확인 후 삭제(되돌릴 수 없음)

## 새 심사 만들기 다이얼로그
- **심사 이름** 입력창(필수, placeholder "예: 33기 파이널 PT 심사")
- **[만들기]** 버튼 — 만들면 곧바로 상세 화면으로 이동해서 이어서 설정

## 채점 링크·QR 다이얼로그 (카드의 🔗 또는 상세 화면 상단 버튼)
- 안내문: "이 링크를 받은 사람은 **로그인 없이** 이름만 입력하고 참여할 수 있습니다. 링크가 **열림** 상태일 때만 제출됩니다."
- **청중 채점 방식이 "등수 선택"인 경우**: 링크가 2개로 분리됨 — "심사위원·청중 순위" 링크/QR과 "청중 피드백" 링크/QR을 나란히 표시(피드백은 팀별 서술형 의견 작성 전용 폼)
- 그 외에는 링크 1개
- 각 QR 블록: QR코드 이미지, 링크 텍스트(읽기전용, 클릭하면 전체 선택), **[복사]** 버튼(클립보드 복사, 안 되면 자동 폴백), **[QR 이미지 저장(PNG)]** 버튼(캡션 포함된 정사각 PNG로 다운로드 — 인쇄해서 배포하기 좋게)

## 코드에 이미 있는 사용법 (ScreenGuide 원문 그대로)
1. **새 심사 만들기** — '새 심사'로 라운드를 만듭니다. 세션을 고르면 그 세션의 팀이 자동으로 심사 대상으로 들어옵니다. 세션 없이 팀을 직접 입력해도 됩니다(외부 대회).
2. **설정 — 기준** — 심사 기준을 영역 → 세부항목 2단계로 짭니다. 예: '주제 적합성 30점' 아래 '문제 재정의 10점' 등. 세부항목을 안 두면 그 영역은 통째로 채점합니다.
3. **설정 — 비중·청중** — 심사위원 vs 청중 비중(합 100)을 정합니다. 청중은 등수 선택 또는 기준 채점 중 고르고, 소그룹(기수·운영진·참관위원 등)을 자유롭게 편집합니다.
4. **설정 — 감점 규정** — 발표자료 지각·발표시간 초과·미달·형식 미준수 같은 감점을 규정으로 정의합니다. 발표시간은 기준 시간만 정해두면 감점 탭에서 실제 발표시간을 입력할 때 자동 계산됩니다. 마감 후 제출은 실격으로 처리할 수 있습니다.
5. **명단·링크 배포** — 명단을 등록하면 '누가 냈는지' 체크됩니다(없어도 됨). '채점 링크·QR'로 링크를 열고 배포하면 로그인 없이 누구나 이름만 넣고 채점합니다.
6. **감점 입력·실시간 집계** — '감점' 탭에서 팀별 감점을 입력하고, '결과' 탭에서 원점수 → 감점 → 최종점수와 순위를 실시간으로 봅니다. 엑셀로도 내보낼 수 있습니다.

## 알아두면 좋은 것
- 라운드 삭제 시 제출된 점수까지 전부 사라짐(되돌릴 수 없음)
- 채점 폼은 완전 무로그인 — 링크만 있으면 누구나 접근(별도 문서 `19-public-scoring-form.md` 참고)
