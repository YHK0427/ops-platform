# 세션 상세 — "정산" 탭 (SETTLEMENT / FINALIZED)

## 진입 경로
- 세션 상세 화면 상단 탭 바에서 "정산" 클릭(세션 상태가 SETTLEMENT 이상이어야 클릭 가능)
- URL: `/sessions/{id}/settlement`
- 이 화면은 세션 상태가 `SETTLEMENT`(마감 전 — 미리보기+수정 가능)인지 `FINALIZED`(마감 완료 — 장부 조회+수정)인지에 따라 완전히 다른 화면이 나타남
- 상세 헤더/탭바/기한표시줄은 "출석" 탭 문서 참고(공통)

---

## A. 마감 전 — "정산 미리보기" 화면 (`SETTLEMENT` 상태)

### 상단
- 제목 "정산 미리보기" + "이번 세션의 페널티 및 정산 예정 내역입니다. 체크박스를 해제하여 면제할 수 있습니다"
- 우측 **"세션 마감" 버튼**(빨간색): 클릭하면 마감 확인 다이얼로그가 뜸(아래 참고)

### 요약 카드 3개
총 벌점 / 총 차감액(원) / 총 상점 — 체크 해제한 항목은 합계에서 자동 제외됨(실시간 반영)

### 벌점(패널티) 표
- 상단 필터: **멤버 필터 드롭다운**(전체 멤버 또는 특정 멤버만), **유형 필터 드롭다운**(전체 유형 또는 출결/PPT/PPT이메일/과제미제출/누적 벌점 중 하나) — 우측에 "N / 총건수" 표시
- 표 열: 적용(체크박스) / 유형(배지) / 멤버 / 사유 / 점수 / 디파짓
- **체크박스 해제**: 그 벌점 항목을 이번 정산에서 면제(적용 안 함) — 단, **"누적 벌점"(마일스톤) 유형은 체크 해제 불가**(항상 강제 적용, 노란 배경으로 구분)
- 체크 해제한 행은 흐리게(반투명) 표시됨

### 상점 패널
- 헤더에 "상점" + 건수 배지, 우측 **"상점 추가" 버튼**
  - **"상점 추가" 다이얼로그**: 프리셋 버튼들(친바 선정팀/Listen Up 1·2등/BP 1·2등/피날래 본선/발전왕/베스트 협력상/오프오피 — 각각 점수+사유 자동 채움), 점수 입력창, 사유 입력창, (팀 세션이면) 팀 단위 일괄선택 버튼, 멤버 검색+체크박스 목록, 선택 미리보기("N명 × +점수 — 사유"). **"추가" 버튼**으로 저장(세션 마감 시 함께 적용되는 "대기" 상태로 저장됨 — 즉시 장부에 반영 안 됨)
- 상점 필터: 멤버 필터 드롭다운
- 상점 표: 적용(체크박스) / 구분("상점" 배지) / 멤버 / 사유 / 점수 / 삭제 버튼(휴지통 아이콘, **수동으로 추가한 상점만** 삭제 가능 — 연속출석 등 자동 계산된 상점은 삭제 버튼 없음)
- 체크박스 해제 시 그 상점도 마감 시 면제됨

### 하단 경고문
"마감 버튼을 누르면 위 내역(체크된 항목)이 장부에 영구 기록되며, 멤버들의 점수와 디파짓이 즉시 반영됩니다. 이 작업은 되돌릴 수 없습니다."

### "세션 마감" 확인 다이얼로그
- **상점 확인 체크박스**(노란 박스, 필수): "오프/오피 등 상점을 모두 부여하셨나요? Listen Up·BP·발전왕·번개 등 빠뜨린 상점이 없는지 마감 전에 꼭 확인하세요" + **"상점을 모두 적용했습니다" 체크박스** — **이 체크박스를 체크해야만 마감 버튼이 활성화됨**
- 정산 요약 재확인(총 벌점/차감액/상점 3칸)
- 안내: "마감하면 위 내역이 장부에 영구 기록되고 멤버 점수·디파짓에 즉시 반영됩니다. 마감 후에도 장부에서 세션에 연결해 상점·벌점을 추가·수정할 수 있어요"
- **"취소"** / **"세션 마감"** 버튼 — 마감 클릭 시 실제 장부 기록 실행, 성공하면 "세션이 성공적으로 마감되었습니다" 토스트와 함께 화면이 아래 B 화면(FINALIZED 뷰)으로 전환

---

## B. 마감 완료 후 — "세션 마감 완료" 화면 (`FINALIZED` 상태)

- 상단: 초록 체크 아이콘 + "세션 마감 완료" + "{마감시각} 마감 · 아래에서 개별 항목을 수정/삭제할 수 있습니다"
- **"장부에서 확인" 버튼**: 전체 장부 화면(`/ledger`)으로 이동
- **엑셀 내보내기 버튼**: 이 주차 정산 결과를 엑셀 파일로 다운로드(파일명에 주차 포함)

### 장부 항목 표 (이 세션에 연결된 항목만)
열: 유형(상점/벌금 배지) / 멤버 / 사유 / 점수 / 금액 / 잔액 / 수정·삭제 버튼

- **연필 아이콘(수정)**: 클릭하면 그 행이 인라인 편집 모드로 바뀌어 사유/점수/금액을 직접 고칠 수 있음. **체크(저장)**/**X(취소)** 버튼으로 확정/취소
- **휴지통 아이콘(삭제)**: 클릭 시 "이 항목을 삭제하시겠습니까? 멤버의 잔액과 점수가 자동으로 조정됩니다" 확인창 → 확인 시 삭제되고 해당 멤버의 점수/잔액이 자동으로 재계산됨

## 알아두면 좋은 것
- 마감(SETTLEMENT→FINALIZED 전환)은 **완전히 되돌릴 수 없는** 핵심 작업 — 확인 체크박스까지 강제해서 실수 방지
- 마감 후에도 개별 장부 항목은 이 화면에서 계속 수정/삭제 가능(단, 마감 자체를 취소하고 SETTLEMENT로 되돌리는 기능은 없음)
- "상점 추가" 다이얼로그로 넣은 항목은 이 탭 안에서만 "대기" 상태이며, 실제로 장부에 기록되는 시점은 "세션 마감" 버튼을 눌렀을 때
