# 사용자 관리

## 진입 경로
- 사이드바 "관리" 구역의 "**사용자 관리**" (방패 아이콘) — **admin 역할만** 보임(manager/viewer는 이 메뉴 자체가 안 보임).
- URL: `/admin/users`

## 화면 구성
- 상단: "관리자" 제목 + "사용자 및 기수 계정을 관리합니다" 부제 + 우측 액션 버튼(admin만: 기수 초기화, 2FA 설정 / 사용자 관리 탭일 때만: 사용자 추가)
- 탭 2개: **사용자 관리** / **기수 관리**
- 각 탭 안에 표 형태 목록

## 버튼/액션 전수 목록

### 상단 액션 버튼 (admin 역할에게만 보임)
- **"기수 초기화"** (빨간 테두리, 되돌리기 아이콘) — 클릭 시 확인 다이얼로그: "모든 세션, 장부, 출석, 과제 기록이 삭제됩니다. 멤버 명단은 유지되며 디파짓이 2만원으로 초기화됩니다. **이 작업은 되돌릴 수 없습니다.**" → **"취소"** / **"초기화 실행"**(빨강) — **가장 파괴적인 액션**, 성공하면 "기수 초기화 완료 — N명 디파짓 2만원 리셋" 토스트
- **"2FA 설정"** (방패 아이콘) — "2단계 인증(TOTP)" 다이얼로그 열림(본인 계정의 2FA 설정, 아래 참조)
- **"사용자 추가"** (사용자 관리 탭일 때만 표시) — "사용자 추가" 다이얼로그 열림(아래 참조)

### 탭 전환
- **"사용자 관리"** / **"기수 관리"** 탭 버튼 — 클릭으로 전환

### "사용자 관리" 탭 — 표
컬럼: 아이디 / 이름 / 역할(배지) / 부서(배지, 없으면 "-") / 2FA(체크 아이콘 또는 "-") / 상태(활성/비활성 텍스트) / 생성일 / (우측) 액션
- 각 행 우측(마우스 올리면 나타남):
  - **연필 아이콘** — "사용자 수정" 다이얼로그(아래 참조)
  - **휴지통 아이콘**(빨강) — 확인 다이얼로그: "OOO(아이디)을(를) 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다." → **"취소"** / **"삭제"** — 파괴적 액션

### "기수 관리" 탭(내부적으로는 "GenerationTab" — 기수원 로그인 계정 관리)
- 상단에 "활성 멤버 N명 중 M명 계정 보유" 요약
- 계정이 1개 이상 있을 때만 보이는 버튼:
  - **"일괄 비번 변경"** — "일괄 비밀번호 변경" 다이얼로그(전체 기수 계정 비밀번호를 한 번에 바꿈)
  - **"일괄 삭제"**(빨강) — 확인 다이얼로그: "기수 계정 N개를 모두 삭제합니다. **이 작업은 되돌릴 수 없습니다.**" → 파괴적 액션
- **"일괄 생성"** 버튼 — 계정 없는 멤버가 있을 때만 활성화. 확인 다이얼로그 안에 비밀번호 입력창(기본값 "univpt33") + 안내("아이디: 멤버 이름 / 이미 계정이 있는 멤버는 건너뜁니다.") → **"취소"** / **"생성"**
- 표: 이름 / 아이디 / 계정 보유 여부(체크/X 아이콘) / 액션
  - 계정 없는 멤버: **"계정 생성"** 버튼 → "계정 생성" 다이얼로그(아이디 비우면 자동 생성, 비밀번호 비우면 기본값)
  - 계정 있는 멤버(마우스 올리면 액션 보임):
    - **연필 아이콘**("아이디 수정") — "아이디 수정" 다이얼로그
    - **열쇠 아이콘**("비밀번호 변경") — "비밀번호 변경" 다이얼로그(비우면 기본값 univpt33)
    - **휴지통 아이콘**(빨강, "계정 삭제") — 확인 다이얼로그 후 삭제

## 폼/입력 필드

### "사용자 추가" 다이얼로그
- **아이디**(필수), **비밀번호**(필수, "6자 이상" 안내), **이름**(필수, 표시 이름), **역할** 드롭다운(관리자/운영진/열람자/외부 임시(심사 전용))
- 역할이 "운영진"일 때만 **부서** 드롭다운 추가 표시(회장단/인홍부/학술부/기획부/총무부)
- 제출: **"생성"**(셋 다 채워야 활성화, 처리 중 스피너)

### "사용자 수정" 다이얼로그
- 아이디, 이름, 역할(드롭다운), (운영진일 때) 부서, **비밀번호**(비워두면 유지 — "변경 시 입력" 안내), **상태**(활성/비활성 드롭다운)
- 제출: **"저장"**

### "2단계 인증(TOTP)" 다이얼로그
- 이미 활성화된 경우: "2FA 활성화됨" 표시 + **"QR 다시 보기 (재등록)"** / **"2FA 해제"**(빨강) 버튼
- 처음 설정: "설정 시작" 버튼 → QR 코드 화면(Google Authenticator 등으로 스캔) + 수동 입력용 시크릿 키 텍스트 + **6자리 OTP 코드** 입력창 → **"확인 및 활성화"** 버튼(코드 6자리 다 입력해야 활성화) → 성공 시 완료 화면 + **"완료"** 버튼

### "일괄 비밀번호 변경" 다이얼로그
- **새 비번** 텍스트(4자 미만이면 제출 불가) → **"변경"** 버튼

### "계정 생성" 다이얼로그 (개별)
- **아이디**(비우면 "이름+기수번호" 자동 생성), **비밀번호**(비우면 "univpt+기수번호" 기본값) → **"생성"**

### "아이디 수정" 다이얼로그
- **아이디** 텍스트(기존 값과 같거나 비어있으면 저장 비활성) → **"저장"**

### "비밀번호 변경" 다이얼로그 (개별 기수 계정)
- 비밀번호 텍스트(비우면 "univpt33"로 설정된다는 안내) → **"변경"**

## 상태별 화면
- **로딩 중**: 표에 회색 스켈레톤 바
- **데이터 없음**: "사용자가 없습니다" / "활성 멤버가 없습니다"
- **2FA 상태 확인 중**: 다이얼로그 열자마자 잠깐 스피너
- **에러**: TOTP 설정/확인 실패 시 토스트("TOTP 설정 실패", "OTP 코드가 올바르지 않습니다.", "비활성화 실패") — 그 외 명시적 에러 UI 없음, 실제 화면 확인 필요.

## 알아두면 좋은 것
- **이 화면 전체가 admin 역할 전용**이다 — manager/viewer는 사이드바에 이 메뉴 자체가 안 보인다.
- "기수 초기화"는 이 앱에서 가장 위험한 버튼 중 하나 — 세션·장부·출석·과제 기록을 전부 지운다(멤버 명단만 남음). 학기/기수가 끝나고 새로 시작할 때만 눌러야 함.
- "사용자 관리" 탭(운영진 로그인 계정)과 "기수 관리" 탭(기수원 로그인 계정)은 완전히 별개 시스템이다 — 헷갈리지 않아야 함. 전자는 대시보드 등 운영 화면 접근용, 후자는 기수원이 자기 성적/피드백을 보는 포털 접근용.
- "일괄 생성"으로 만들어지는 기수 계정 아이디는 "멤버 이름" 그대로다(중복되면 자동으로 뒤에 기수번호가 붙을 수 있음 — 로그인 관련 기수 분리 로직 참고).
