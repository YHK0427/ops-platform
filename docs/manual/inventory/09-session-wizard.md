# 새 세션 생성 (마법사)

## 진입 경로
- "전체 세션" 화면 우측 상단 "새 세션" 버튼, 또는 세션이 하나도 없을 때 "첫번째 세션 생성하기" 버튼
- 사이드바 "세션" 섹션 → "새 세션" 메뉴(있는 경우)
- URL: `/sessions/new`
- 총 2~3단계 마법사(세션 타입에 따라 단계 수 다름). 상단에 "N단계 중 M단계" 표시

## 화면 구성 및 단계 흐름
- **1단계: 기본 설정** → 항상 표시
- **2단계**: 세션 타입이 "팀 세션"이면 **팀 빌딩**, "개인 발표"이고 "분반 나누기" 체크했으면 **분반 나누기**. 둘 다 아니면 2단계 건너뜀
- **3단계(또는 2단계): 최종 확인** → 항상 마지막에 표시

---

### 1단계: 기본 설정
카드 제목 "1단계: 기본 설정"

**입력 필드**
- **주차** (숫자 입력, 최소 1)
- **세션 날짜** (날짜 선택기) — 날짜 바꾸면 아래 제출기한들이 자동으로 재계산됨(전날 21:59 / 당일 09:59 / 다음 수요일 21:59 규칙)
- **세션 주제** (텍스트, 예: "자유주제 발표") — 입력하면 바로 밑에 "영상 파일명 예시: N주차_주제_이름.mp4" 안내 문구가 나타남
- **세션 타입** (드롭다운): "개인 발표" / "팀 세션" — 팀 세션 선택 시 "다음 단계에서 팀 빌딩을 진행합니다" 안내
- **세션 옵션** (체크박스, 2열 그리드):
  - PPT 이메일 제출
  - PPT 게시판 포함
  - 리뷰 포함
  - 영상 피드백 포함
  - 분반 나누기 (2개 그룹) — **개인 발표 타입일 때만 보임**
  - 휴일 (벌점 면제) — 빨간 글씨, 체크하면 이 세션은 지각/결석 벌점이 면제됨
- **제출 기한 설정** (위 옵션 중 하나라도 체크했을 때만 나타남):
  - PPT 이메일 제출 기한 (날짜+시간)
  - PPT 이메일 지각 제출 기한 (날짜+시간)
  - 후속 과제 기한 — 리뷰/PPT게시판/피드백 공통 (날짜+시간)

**버튼**
- **"취소"** (좌측 하단, 좌측 화살표 아이콘): 브라우저 뒤로가기(바로 이전 화면으로)
- **"다음: 팀 빌딩" 또는 "다음: 확인"** (우측 하단, 세션 타입에 따라 라벨 바뀜): 주차>0, 주제 입력, 날짜 입력이 모두 채워져야 활성화됨(안 채우면 버튼 비활성). 클릭하면 다음 단계로 이동(아직 서버에 저장 안 됨 — 메모리상에서만 진행)

---

### 2단계 (A): 팀 빌딩 — 세션 타입이 "팀 세션"일 때
제목 "Team Building". 드래그앤드롭으로 멤버를 팀에 배정하는 보드.

**구성**
- 좌측(모바일은 상단): "미배정" 칼럼 — 이름 검색창 있음
- 우측: 팀 칼럼들 (기본 없음, 직접 추가)
- 각 멤버는 카드로 표시, 카드 우측에 드래그 손잡이(≡ 아이콘)

**버튼/액션**
- **"팀 추가"** (상단 좌측): 새 팀 칼럼 추가(이름 자동 "N조")
- **선택 후 "[N명] 이동" 버튼** (멤버 카드를 탭해서 선택하면 나타남): 팝오버가 열리고 "미배정" 또는 팀 목록 중 하나를 클릭하면 선택된 멤버 전원이 그 팀으로 일괄 이동
- **"선택 해제"** (선택된 멤버 있을 때만): 선택 초기화
- **"자동 생성"** (상단 우측, 마법봉 아이콘): 활성 멤버를 랜덤 셔플 후 4명씩 묶어 자동으로 팀 생성(기존 배정 덮어씀)
- **멤버 카드 클릭(카드 본문)**: 체크박스 토글(선택/해제) — 여러 명 동시 선택 가능
- **멤버 카드 드래그(우측 손잡이)**: 다른 팀 칼럼으로 드래그해서 이동. 여러 명 선택한 상태에서 하나를 드래그하면 선택된 멤버 전원이 같이 이동
- **팀 칼럼 제목 클릭**: 팀 이름 인라인 수정(연필 아이콘). Enter로 확정, Esc로 취소. 이미 있는 이름으로 바꾸면 "이미 존재하는 팀 이름입니다" 에러
- **팀 칼럼 우측 상단 X 버튼**: 그 팀 삭제 — 소속 멤버는 전부 "미배정"으로 돌아감
- **이름 검색창** (미배정 칼럼 상단): 입력한 글자가 포함된 이름만 필터링해서 보여줌
- **"이전"**: 1단계로 복귀
- **"다음: 확인"**: 3단계로 이동(팀 배정 상태 저장하고 진행)
- **리더 태그 충돌 경고**: 한 팀에 리더 태그(`leader`)를 가진 멤버가 2명 이상 있으면 노란색 테두리로 경고 표시(진행은 막지 않음)

---

### 2단계 (B): 분반 나누기 — 세션 타입이 "개인 발표" + "분반 나누기" 체크했을 때
제목 "분반 나누기". 위 팀 빌딩과 같은 드래그앤드롭 UI를 재사용하되, 칼럼이 "1분반"/"2분반"으로 고정(팀 추가/삭제/이름변경 불가).

**추가 구성 — 운영진 배치** (staff 목록이 있을 때만 표시)
- 상단 박스에 전체 운영진 이름이 나열되고, 각 이름 옆에 **"1" / "2" 버튼**이 있어 그 운영진을 1분반 또는 2분반 담당으로 지정(토글 — 다시 누르면 해제, 파란색=1분반/초록색=2분반)

**버튼/액션**
- 자동 생성 버튼 라벨은 "자동 분배"(활성 멤버를 반으로 나눠 1분반/2분반에 랜덤 배정)
- 나머지 카드 선택/이동/드래그 동작은 팀 빌딩과 동일하나, 팀 추가/삭제/이름변경 버튼은 없음
- **"이전"** / **"다음: 확인"**

---

### 3단계(또는 2단계): 최종 확인
카드 제목 "Step 3: 최종 확인" — 지금까지 입력한 내용을 요약해서 보여주는 읽기 전용 화면

**표시 내용**: 주차, 날짜, 주제, 타입, (팀이면) 배정된 팀 수, (분반이면) 1분반/2분반 인원수, (기한 설정했으면) PPT 이메일 기한/지각 기한/후속 과제 기한

**버튼**
- **"이전"**: 이전 단계로 복귀(입력 내용 유지)
- **"세션 생성 완료"** (녹색 버튼, 체크 아이콘): 클릭 시 실제로 서버에 저장 진행 —
  1. 세션 생성 API 호출
  2. (팀 세션이면) 팀 배정 저장
  3. (분반 세션이면) 분반+운영진 배치 저장
  4. 성공하면 "세션이 성공적으로 생성되었습니다" 토스트 뜨고 새로 만든 세션의 PREP 탭(`/sessions/{id}/prep`)으로 자동 이동
  5. 실패하면 "세션 생성 중 오류가 발생했습니다" 토스트, 화면에 남음(재시도 가능)
  - 처리 중에는 버튼이 스피너로 바뀌고 비활성화(중복 클릭 방지)

## 알아두면 좋은 것
- 1~3단계 사이 이동은 전부 **로컬 메모리**에서만 이루어지고, 실제 서버 저장은 마지막 "세션 생성 완료" 버튼을 눌러야만 일어남 — 중간에 브라우저를 닫으면 전부 사라짐
- 팀/분반 배정은 나중에 세션 상세의 "팀 편집"/"분반 편집" 화면에서 다시 조정 가능(별도 문서 참고)
- "휴일" 체크는 되돌리기 쉬운 옵션이 아니라 정산 로직에 직접 영향을 주므로 신중히 체크할 것
