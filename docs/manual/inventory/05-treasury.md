# 금고 (총무부시점)

## 진입 경로
- 사이드바 "**금고(총무부시점)**" (돼지저금통 아이콘) — 모든 운영진(admin/manager/viewer)에게 보임.
- URL: `/treasury`

## 화면 구성
- 상단: "금고" 제목 + "동아리 재정 현황" 부제(별도 액션 버튼 없음)
- 요약 카드 2개(2열 그리드, 모바일은 세로):
  - **금고 (운영 자금)** — 파란 테두리
  - **기수 자금** — 청록 테두리
- 탭 5개 + 우측(또는 모바일 전용 상단) 액션 버튼 2개
- 탭 내용: 데스크탑은 표, 모바일은 카드 리스트

## 버튼/액션 전수 목록

### 요약 카드
- 순수 정보 표시 카드로 클릭 액션 없음
- **금고(운영 자금)**: 순잔액(수입-지출) + 세부 내역(벌금 수입, 이탈자 디파짓 몰수, 누적벌점 벌금 납부완료분, 미납 있으면 강조 표시, 지출 있으면 표시)
- **기수 자금**: 전체 멤버 디파짓 합계 + 활성 멤버 수 + 1인 평균 잔액 + "수료 시 환급 예정" 금액 + 안내문("기수 종료 시 수료자에 한해 잔여 디파짓 환급")

### 액션 버튼 (모바일은 탭 위에 별도로, 데스크탑은 탭 줄 우측 끝에)
- **"지출 기록"** (빨강) — "금고 지출 기록" 다이얼로그 열림
- **"누적벌점 벌금"** (노랑/호박색, + 아이콘) — "누적벌점 벌금 추가" 다이얼로그 열림

### 탭 5개
1. **세션별** — 세션마다 벌금 합계·누적벌점 합계·총합
2. **멤버별** — 멤버마다 벌금 합계·누적벌점 합계·총합
3. **미납 현황** (미납 건수가 있으면 탭 라벨에 "(N)" 표시) — 각 행에 **"납부 확인"** 버튼(누르면 즉시 납부완료 처리 — 별도 확인창 없이 바로 처리됨)
4. **지출** (건수 있으면 탭 라벨에 "(N)" 표시) — 지출 내역 + 각 행 휴지통 아이콘(삭제)
5. **전체 내역** — 벌금/이탈몰수/누적벌점 전체를 하나로 모아 시간순(멤버·세션·구분 배지·금액·설명·날짜)

### "지출" 탭의 각 행
- **휴지통 아이콘** — 확인 다이얼로그: "'설명' (금액) 지출 기록을 삭제하시겠습니까?" → **"취소"** / **"삭제"**(빨강) — 파괴적 액션

## 폼/입력 필드

### "누적벌점 벌금 추가" 다이얼로그
- **멤버** 드롭다운(필수)
- **금액(원)** 숫자(기본값 5000)
- **설명** 텍스트(기본값 "누적벌점 벌금")
- 버튼: **"취소"** / **"추가"**(멤버·금액 없으면 비활성, 처리 중 "처리 중...")

### "금고 지출 기록" 다이얼로그
- **금액(원)** 숫자(필수)
- **사용 내역** 텍스트(필수, 예: "간식 구매, 회식비 등")
- 버튼: **"취소"** / **"기록"**(금액·내역 없으면 비활성, 처리 중 "처리 중...")

## 상태별 화면
- **로딩 중**: 화면 중앙 스피너
- **탭별 데이터 없음**: 탭마다 다른 문구("벌금 내역이 없습니다" / "미납 내역 없음"(초록색으로 긍정적 표시) / "지출 내역 없음" / "내역이 없습니다")
- **에러**: 코드상 별도 에러 UI 없음 — 실제 화면 확인 필요.

## 알아두면 좋은 것
- 이 화면은 **장부(기수시점)**와 다른 관점이다 — 장부는 "멤버 개인의 디파짓/점수" 기준이고, 금고는 "동아리 운영 자금(총무부 입장)" 기준이다. 같은 벌금 데이터를 다른 각도로 보여줌.
- "미납 현황" 탭의 "납부 확인" 버튼은 **확인 창 없이 바로 처리**된다(멤버 상세·장부 화면의 동일 기능은 확인창이 뜨는 것과 다름) — 실수로 누르지 않게 주의.
- "기수 자금"(멤버 디파짓 총합)은 아직 멤버들에게 돌려줘야 할 돈이라는 의미이지, 동아리가 쓸 수 있는 돈이 아니다 — "수료 시 환급 예정"이라는 문구가 이를 명시함.
